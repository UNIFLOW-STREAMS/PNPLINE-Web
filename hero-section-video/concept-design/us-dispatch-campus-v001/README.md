## 디자인 방향

**정돈된 출고 마당에서 미국의 작은 상업·주거 블록으로 퍼져 나가는 배송 흐름.**

기존의 긴 단면 창고, 상부 오른쪽 도시대, 출고 마당과 하나의 Y자 도로를 시각적 뼈대로 사용했다. 창고가 중심이고 저층 건물군은 목적지의 다양성을 암시한다. 원래 빈 블록 프록시는 2~4층의 석재·벽돌 모듈로 발전시킨다. 이미지의 여덟 동은 밀도 제안이며 확정 개수는 아니다.

- 창고: 아이보리 단열 금속 패널, 남색 골강판, 청색 포인트, 지붕 두께·철골·랙의 구조가 읽히는 고정 개방면.
- 저층 건축: 크림색 석재 코니스·창틀과 붉은 벽돌, 움푹 들어간 창과 상가 입면, 소수의 녹색 어닝. 옥상은 파라펫·해치·소형 HVAC로 반복감 완화.
- 도로: 따뜻한 짙은 회색 아스팔트, 절제된 흰 차선, 밝은 연석·보도·배수구. 분기점 자체는 명료하게 비워 둔다.
- 조경: 건물 사이와 도로 바깥을 중간 크기 활엽수·관목으로 연결한다. 분기 중앙은 낮은 녹지와 빗물정원으로 해석한다.
- 마당: 콘크리트 패널 줄눈, 출고 대기 공간, 문 옆 고무 범퍼와 노란 보호대. 차량 궤적 안에는 설비를 두지 않는다.
- 조명: 밝고 부드러운 주광, 절제된 반사와 표면 사용감. 물류 차량이 배경에 묻히지 않도록 건물은 중성색을 중심으로 둔다.

## 모델링 모듈 제안

아래 비례는 실제 치수가 아닌 시작용 조형 지침이다. 기존 Blender 오브젝트와 실제 카메라에서 최종 크기를 정한다.

| 모듈 | 형태·반복 방법 | 우선순위 |
| --- | --- | --- |
| B01 벽돌 코너 상가 | 2층, 석재 코니스·파라펫, 녹색 어닝, 측면 서비스 출입구 | 높음 |
| B02 밝은 석재 도시 주택 | 3층, 창 모듈 반복, 얕은 발코니, 옥상 장비 | 높음 |
| B03 벽돌 서비스동 | 2층, 단순한 후면·적재 출입구, B01과 공용 창 모듈 | 중간 |
| B04 석재 코너 변형 | 3~4층, B02의 코너·창 간격·지붕 높이 변형 | 중간 |
| W01 창고 외피 | 현 창고 메시와 개방면을 따르는 패널·철골 마감 | 높음 |
| W02 출고 인터페이스 | 문틀·고무 범퍼·도크 플레이트·측면 보호대 | 높음 |
| R01 도로·보도 | 현 도로 중심선 위 차선, 연석·보도·배수 반복 모듈 | 높음 |
| L01 조경 | 활엽수 3개 정도의 수형 변형, 낮은 관목·지피 | 높음 |
| P01 소품 | 가로등·벤치·작은 옥상 장비, 필요 구도에만 배치 | 낮음 |

저층 건물은 기존 상부 도시 빌딩보다 확실히 낮게 유지한다. 건물 폭과 높이는 같은 모듈을 획일적으로 복사하기보다 층수·코너·입면 재료·옥상 장비를 바꿔 변주한다. 잔디와 아스팔트에 과도한 노이즈를 주지 않는다.

## Blender 적용 시 지켜야 할 사항

- 최신 장면 포인터를 다시 확인한다. 이번 조사 시 blockout 포인터는 `us-title-curve-v001/pnpline-us-title-curve-v001.blend`, lookdev 포인터는 `lookdev/hero-material-v001/pnpline-hero-material-v001.blend`였다.
- 생성 이미지에서 도로 곡선·해안선·창고 비례가 일부 달라질 수 있다. 실제 Blender의 통합 지형·구면 곡률·도로 궤적을 기준으로 모델링한다. 이미지의 해안선을 그대로 트레이싱하지 않는다.
- 창고 도크 문은 이미지에서 닫힌 상태로 묘사되어 있다. 이는 외관 샘플이며 기존 문 개폐·화물 접점·출고 타이밍을 대체하지 않는다.
- 이미지의 작은 주차 차량과 보조 소품은 필수 애셋이 아니다. 기존 출고 차량 ID와 위치·타이밍을 우선하며 새 차량을 복제해 동작을 채우지 않는다.
- 도로 끝은 더 넓은 육지의 배송 방향으로 이어진다는 해석이다. 최종 컨셉은 도로가 바다에서 막히던 초안의 문제를 수정했다. 기존 메시 경계를 확장할지는 별도 모델링 판단 사항이다.
- 분기점 중앙의 나무는 이미지상 상대적으로 크게 보인다. 모델링에서는 꼭짓점에 낮은 관목을 쓰고 큰 나무를 뒤로 물려 차량과 도로 분기가 보이도록 한다.
- 원테이크 카메라의 전체 점유 공간과 차량의 회전·후진 궤적을 먼저 확인한 뒤 건물·나무·가로등을 배치한다. 이번 단계에서는 씬 좌표의 충돌·가시성 검증을 수행하지 않았다.
- 구조물은 해당 위치의 지구 법선에 정렬하고 보도·도로 마감은 기존 지형에 맞춘다. 별도의 평평한 받침판을 추가하지 않는다.
- 컷아웃을 위한 새 지붕 사라짐 효과, 큰 도로 시설, 지도 핀·발광 경로·실제 서비스 범위·처리량 문구를 추가하지 않는다.

## 제작 기록

내장 `image_gen` 도구와 `imagegen` 스킬로 생성했다. 정확한 이미지 모델명은 도구 응답에 노출되지 않아 GPT Image 2.5로 표기하지 않았다. Higgsfield는 이번 산출물 생성에 사용하지 않았다. 원본 Blender 파일은 열거나 수정하지 않았다.

전체 초안 → 하단 지형·도로 연속성 수정 → 모듈 상세 보드 순으로 제작하고 생성 결과를 직접 확인했다. 이 두 최종 이미지는 외관·밀도·재질 방향을 전달하며, 모델링 구현이나 동작 검증 완료를 뜻하지 않는다.
