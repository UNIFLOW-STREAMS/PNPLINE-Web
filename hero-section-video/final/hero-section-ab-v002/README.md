# Hero Section A/B v002 후보 작업

v001의 A/B 장면을 바탕으로 적재 작업과 트럭 출발 시점을 조정하고 일부 가로수 수관에 청록색을 적용하는 후보 작업이다. 이 기록을 추가하는 시점의 대표 A/B 파일과 최신 포인터는 v001이며, v002를 대표 장면으로 채택하거나 게시하지 않았다.

## 변경 내용

- 작업자, 손과 받침, 상자, 카트 및 트럭에 연결된 애니메이션을 함께 리타이밍한다. 주 적재 이동을 약 23프레임에서 45프레임으로 늘리고 트럭 출발을 870에서 900프레임으로 늦추며 989프레임 종점으로 연결한다.
- 작업자 다리에 교대 발 들기 보정을 적용한다. 실제 보행 품질과 장면 연속성은 별도 시각 검토 대상이다.
- WC 가로수의 수관 재질 슬롯을 개체 이름의 고정 해시로 선택해 청록색을 적용한다. A/B의 동일한 수관 395개가 대상이다.
- A-changes.json과 B-changes.json은 입력·출력 해시, 애니메이션 대상, 시간 매핑 및 수관 선택 목록을 기록한다. 보존 여부는 제작 스크립트가 기록한 검사 결과이며 이번 Git 정리에서 전체 Blender 검증을 다시 수행한 것은 아니다.

## 추적 파일과 로컬 산출물

Git에는 이 설명, A/B 변경 기록과 scripts/build.py, scripts/review.py, scripts/publish.py를 보관한다. 중복 Blender 사본, 로그, review 아래 이미지·프레임·측정 데이터와 검토 영상은 기존 제외 규칙에 따라 로컬에 보관한다. 새로 복제한 저장소에는 이 산출물이 없다.

build.py는 Blender에서 연 입력 장면을 기준으로 마지막 인수 A 또는 B에 해당하는 후보를 생성한다. scripts는 v001의 state.py와 과거 재질 실험의 검토 페이지 패키징 도우미를 참조한다. review.py는 비교 이미지와 B의 동작 프레임을 출력한다. publish.py는 렌더 자료를 확인한 후 대표 A/B 파일과 최신 포인터를 덮어쓰므로, 실제 채택할 때 별도로 실행한다. 이번 커밋 과정에서는 실행하지 않았다.
