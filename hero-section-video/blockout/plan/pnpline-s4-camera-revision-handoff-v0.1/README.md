# PNPLINE S4 카메라 수정 인계

`pnpline-s4-camera-revision-codex-v0.1.md`와 `references/`의 영상·S4 보드 5장을 Codex에 함께 제공한다. `review/`는 제출 녹화의 시각적 검토 자료다.

편집할 `.blend`와 생성/수정 코드는 포함하지 않았다. 사용자가 현재 사용하는 최신 Master와 S2/S3 수정 상태를 확인해야 한다. 과거 커밋으로 되돌리거나 구형 생성기로 최신 작업을 덮어쓰지 않는다.

이 묶음은 수정 지시서 및 입력이다. 카메라 수정, Blender 실행/렌더/테스트, 레포 변경은 수행하지 않았다. 영상의 초수는 Blender 타임라인과 동일하지 않다. 비교 이미지에는 생성 프레임·수정 후 결과가 없다.
