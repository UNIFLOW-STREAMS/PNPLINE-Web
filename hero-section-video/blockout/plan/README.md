# PNPLINE S2 스타일프레임 고정 기준 인계 v0.2

Codex에 TASK.md와 references/s2-styleframe-001.png를 함께 전달하세요.

## 포함
- TASK.md: 이전의 디자인 제외·완화 지시를 철회한 독립 실행 지시서.
- references/s2-styleframe-001.png: 사용자가 선택한 원본 이미지, 변경하지 않음.
- INPUT-MANIFEST.json: 이미지 해시·입력 기준·확인 범위.
- SOURCES.md: 조회한 레포 근거와 모델 안내.
- CHECKSUMS.json: 패키지 구성 파일 해시.

## 포함하지 않음
Blender 원본/수정본, 구현 코드, 렌더 결과, 폰트 파일은 포함하지 않습니다.
Blender 원본은 TASK.md의 레포 경로와 사용자 실제 작업본을 Codex 환경에서 대조해야 합니다.

이번 인계서는 작성·패키징된 상태입니다. 레포 수정, Blender 실행·렌더·테스트,
Codex 전송·실행, 커밋·push·배포는 수행하지 않았습니다.
