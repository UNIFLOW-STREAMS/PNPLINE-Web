# 중국 미니어처 도시 확장 v001

작업 파일은 `pnpline-cn-city-expansion-v001.blend`입니다. 중국·미국 작업을 통합한 `../cn-us-integrated-v001/pnpline-cn-us-integrated-v001.blend`에 베이징·광저우 건물군을 추가했습니다. 원본 파일은 보존합니다.

## 모델링

사용자가 제공한 베이징·광저우 컨셉 이미지를 기준으로, 기존 상하이 도시의 서쪽·뒤쪽·동쪽에 두 도시의 건축 요소를 배치했습니다. 실제 지리 배치가 아닌 미니어처 구성입니다.

- 베이징 6종: CCTV 형태의 개방형 타워, 중국존, 국가체육장, 천단, 자금성·천안문 궁궐군, 만리장성과 산림 언덕.
- 광저우 7종: 광저우 타워, IFC·CTF·사선형 유리 타워, 쌍둥이 조개형 공연장, 영남 전통 건축군, 다층 탑.
- 주변 건물 247채: 후퉁 가옥 48채(중정형 단지 12곳), 소형 전통 가옥 82채, 아케이드 상가 40동, 중·고층 건물 77동.
- 곡면 확장 지형, 지형에 맞춘 기초, 도로와 보행로, 수로·아치교, 가로수·조명·광장.

궁궐의 붉은 벽과 황금색 지붕, 천단의 청색 삼중 지붕, CCTV의 빈 중앙과 사선 외골격, 국가체육장의 격자, 광저우 타워의 비틀린 허리와 개방형 격자, 전통 상가의 아케이드·창틀·난간을 메시로 제작했습니다. 주요 고층 랜드마크는 높이 21–33, 주변 중층 건물은 대체로 3.6–8.2의 장면 단위를 사용하며 앞쪽 전통 건물은 더 낮게 구성했습니다.

`CNX_BEIJING_GUANGZHOU` 컬렉션에서 추가 건물과 지형을 편집할 수 있습니다. 랜드마크별 루트와 재질별 메시로 나누었으며, 반복 장식은 배치 메시로 묶었습니다. 외부 생성 모델이나 재생용 스크립트가 필요하지 않습니다.

## 기존 작업 보존

기존 33초·30fps·990프레임 카메라, 렌즈, 하역·선박·운송·창고 애니메이션을 유지했습니다. 새 육지 위로 노출된 기존 장식 물결 9개만 렌더·뷰포트에서 숨겼습니다. 해당 오브젝트의 원본 메시와 애니메이션은 남아 있으며, 이름은 `delivery.json`의 `original_visibility_exceptions`에 기록합니다.

Blender를 열면 추가 구역 전체를 살펴볼 수 있는 편집용 조감 뷰가 표시됩니다. 본편 카메라는 기존 통합본의 동선과 구도를 유지하며, 전체 모델 검토에는 `review.html`의 조감도·도시별 뷰를 사용합니다.

## 검증 및 재현

`review` 폴더의 검증 자료는 기존 오브젝트·액션·재질 보존, 990프레임 카메라·동작 비교, 신규 건물과 원본 건물·이동 객체의 충돌, 카메라 통과, 기초와 언덕의 지형 접지를 검사합니다. 최종 파일 해시와 검증 상태는 `delivery.json`에 기록합니다.

Blender 5.1에서 `scripts/build.py`를 실행하면 통합 원본을 읽어 확장본을 생성합니다. `beijing.py`, `guangzhou.py`, `citykit.py`는 건축 모델을 생성하며, `render_review.py`는 원본을 저장하지 않고 검토용 이미지를 렌더링합니다. 검토 이미지의 Workbench 조명은 원본 장면 카메라와 별개인 임시 조감 뷰에서도 사용됩니다.
