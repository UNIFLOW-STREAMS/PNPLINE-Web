# 중국 도시 배치 및 구면 지형 통합 v001

이 작업본은 `../cn-city-expansion-v001/pnpline-cn-city-expansion-v001.blend`를 바탕으로 제작했습니다. 이전 작업본은 덮어쓰지 않았습니다.

## 요청한 배치 수정

- CCTV 형태의 랜드마크를 오른쪽 도시 구역으로 옮겼습니다.
- 천단을 CCTV의 기존 자리 쪽으로 옮기고 가로·세로·높이를 각각 1.5배로 확대했습니다.
- 자금성·천안문 궁궐군을 오른쪽 전통 건축 구역으로 옮겼습니다. 기존 영남 전통 건축군은 왼쪽의 빈 자리로 재배치했습니다.
- 주변 저층·중층 건물, 거리와 수로를 새 랜드마크 위치에 맞춰 재구성했습니다.

## 하나로 연결된 지형

항만, 상하이, 베이징·광저우 확장 구역은 반지름 141.25의 단일 구면 지형을 공유합니다. 이전의 평평한 바닥과 절벽 형태의 연결부는 새 지형으로 대체했습니다. 지형은 연결된 하나의 닫힌 메시이며, 도로·정원·하천은 곡면 위의 얇은 표면으로 남겼습니다. 하천의 기존 섬 구멍도 유지했습니다.

기존 항만 아래에서 높게 변형되어 있던 해수면을 원래의 지구 표면으로 복원했습니다. 미국 등 다른 지역의 해수면 정점은 유지합니다. 건물, 컨테이너 적재 묶음, 차량, 나무, 조명과 크레인은 개별 형태를 유지하며 해당 위치의 지구 법선에 맞춰 회전·배치했습니다. 넓은 건물의 기초는 곡면에 맞도록 연결했습니다.

`CNC_UNIFIED_CHINA` 컬렉션에는 새 통합 지형과 재배치한 확장 구역, 보정용 객체가 들어 있습니다. 원래 건물의 이름과 재질은 유지하며, 이전 바닥 객체는 숨김 처리하고 `cnc_replaced_by` 속성으로 대체 지형을 기록했습니다.

## 애니메이션

원래의 하역 키와 타이밍을 유지하고, 작업 크레인·스프레더·선박·화물에 같은 위치 보정을 적용했습니다. 스프레더가 분리된 뒤에는 선박을 구면 해수면에 맞추며 기존 항해 동선으로 연결합니다. 중국 구간 카메라에는 지형 변경에 필요한 위치 보정을 적용하고 기존 연출을 유지합니다. 미국 구간은 원래의 카메라와 동작을 유지합니다.

33초, 30fps, 0–989프레임 타임라인은 그대로입니다. `time-map.json`은 기존 시간 매핑을 유지합니다.

## 검토 자료

`review.html`에서 수정 전후 조감도, 지역별 배치와 실제 카메라 프레임을 확인할 수 있습니다. 미리보기는 모델링 확인용 Workbench 렌더입니다. 검증 결과와 최종 파일 해시는 `delivery.json` 및 `review` 폴더에 기록합니다.

`scripts/build.py`는 읽기 전용 원본을 불러와 이 작업본을 다시 생성합니다. `terrain.py`는 단일 곡면과 해수면 복원을, `city_district.py`는 확장 구역 배치를, `animation_reflow.py`는 원래 동작을 유지하는 보정을 담당합니다.
