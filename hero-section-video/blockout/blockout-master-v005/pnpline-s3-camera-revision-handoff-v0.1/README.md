# PNPLINE S3 카메라 수정 인계 묶음

`pnpline-s3-camera-revision-codex-v0.1.md`가 실행 지시서다.
`references/`에는 사용자 원본 보드 6장과 녹화 영상이 있다.
`review/`에는 검토 요약과 비교 시트가 있다. 비교 시트의 시간은 녹화 시간이며 Blender 프레임과 동기화된 값이 아니다.

현재 작업 중인 `.blend`와 생성/검증 소스를 Codex에서 별도로 확인해야 한다. 특히 로컬 S2 수정본을 오래된 레포 결과로 덮어쓰지 않는다.

이 묶음에는 수정된 Blender 결과나 실행 완료 증거가 들어 있지 않다. 검토·인계 문서만 생성했다.
