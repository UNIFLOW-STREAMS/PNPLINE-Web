# 중국 미니어처 전면 항만

`master-cn-port-layout-v001.blend`가 이번 항만 수정본입니다. 이전 중국 작업 세션에서 저장한 모델을 이어서 완성하며, 기존 원본은 `inputs/base.blend`에 보존합니다.

## 배치와 모델

- 표시된 전면 해안에 긴 부두와 4열의 컨테이너 적재 구역을 구성했습니다.
- 컨테이너 127개를 1–3단으로 쌓았으며, 청록·청색·아이보리 재질, 측면과 지붕의 골판, 모서리 프레임, 문과 잠금봉을 모델링했습니다.
- 기존 하역 크레인을 새 항만으로 옮기고 보조 크레인 2기를 배치했습니다.
- 접안 선박, 영향을 받는 가로수·트럭·계선주·바위를 재배치했습니다. 부두 기초와 주변 수면도 조정했습니다.
- 도로, 작업 통로, 레일, 방충재, 계선주, 조명, 관리동과 차량을 추가했습니다.

## 애니메이션 보존

이 작업본은 이전 중국 작업의 12fps, f0–1392 시간축을 유지합니다. 별도로 작업한 미국 도시/33초 영상 파일을 덮어쓰거나 통합하지 않았습니다.

원본 액션을 수정하지 않고 배치용 부모 오브젝트를 추가했습니다. 선박·컨테이너·화물·스프레더의 하역 상대 위치와 f72 안착을 유지합니다. 크레인 발 4개는 부두에 닿으며, 로프 연결 및 크레인 내부 간섭을 검사했습니다. 새 부두와 출항 선박의 교차도 검사합니다.

카메라의 키프레임·행렬·렌즈는 원본 그대로입니다. 검토 이미지와 영상에 사용한 카메라는 파일에 저장하지 않은 임시 카메라입니다. 최종 카메라 모션·앵글·동선 설계는 다음 작업 범위입니다.

출항 위치 보정은 f252까지 유지하고 f360에 기존 항로로 연결합니다. 이 연결은 다음 동선 작업을 위한 임시 처리입니다. 하역 구간 f0–156은 선체 바닥 표본 전체가 수면에 잠기지만, 임시 복귀 구간 f272–336에는 선수 일부가 수면 위로 노출됩니다. f300의 최대 노출은 1.1743m입니다. 다음 동선 작업에서 이 구간의 선체·수면 관계를 함께 조정해야 합니다. 자세한 표본은 `review/static-audit.json`에 기록했습니다.

## 확인 파일

- `review/review.html`: 수정 전후 전체·항만·평면 이미지와 하역 영상입니다.
- `review/after-overview.png`: 수정 후 전체 배치입니다.
- `review/after-hoist.mp4`: 실제 Blender 프레임으로 만든 하역 검토 영상입니다.
- `review/after-hoist-contact-sheet.png`: 하역 주요 프레임입니다.
- `delivery.json`: 최종 파일 해시와 검증 자료를 기록합니다.

검증은 표본 프레임의 지오메트리·변환 비교이며 강체 물리 시뮬레이션은 아닙니다. 카메라를 새 배치에 맞춰 연출한 최종 영상은 이번 산출물에 포함하지 않습니다.

## 재현

Blender 5.1에서 원본을 열고 `scripts/build.py`를 실행합니다. `scripts/harbor_water.py`는 같은 디렉터리에 있어야 합니다. 이 명령은 항만 작업본을 다시 저장합니다.

```powershell
& 'C:/Program Files/Blender Foundation/Blender 5.1/blender.exe' --background --factory-startup 'F:/pnpline-landing/hero-section-video/blockout/cn-port-layout-v001/inputs/base.blend' --python-exit-code 1 --python 'F:/pnpline-landing/hero-section-video/blockout/cn-port-layout-v001/scripts/build.py'
```

검증 스크립트와 `render_review.py`는 마스터를 읽어 검사·렌더만 수행하며 Blender 파일을 저장하지 않습니다.
