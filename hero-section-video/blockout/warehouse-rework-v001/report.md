# PNPLINE 창고 리모델링 · v008

최종 모델은 `candidate-warehouse-v008.blend`입니다. 현재 저장소의 `main`에서 작업했으며 별도 워크트리를 만들지 않았습니다. 이전 arrival 작업과 원본 파일을 유지했습니다.

## 적용한 디자인

- 참고 이미지의 네이비 산업용 외벽, 큰 전면 간판, 열린 내부, 지붕 트러스와 조명, 고밀도 4단 적재 랙, 순환 컨베이어를 모델링했습니다.
- 실제 `PNP-LINE.webp` 실루엣을 메시로 만들어 간판에 사용했습니다. 로고의 청록색 **#00ABE1**, 회색 **#787879**를 사용하고 초록색 강조색은 가져오지 않았습니다. Cycles 재질에는 sRGB → 선형 변환을 적용했습니다.
- 8개 랙, 93개 적재 화물, 14개 순환 컨베이어 화물, 포장 설비와 양 끝 도크를 배치했습니다. 컨베이어는 물리적 상판을 가진 닫힌 경로이며 화물은 경로를 따라 연속 이동합니다.
- 기존 카메라에서 입고 과정이 보이도록 앞쪽 왼쪽 모서리는 정적인 절개 구조로 만들었습니다. 뒤쪽 기둥과 상부 보강재로 형태를 연결했습니다. 완전히 닫힌 실제 건축 외관과는 차이가 있습니다.

## 검증

최종 v008을 다시 열어 검증했습니다. 창고 계약 3개와 운영 검사 8개, **총 11개 모두 통과**했습니다. 차량 53개 구성 메시와 고정 구조물 376개를 **3,126개 시점**에서 검사해 간섭 0건을 확인했습니다. 창고 외 **8,613개 객체** 및 카메라/렌즈, 재질, 월드, 타임라인은 원본과 동일했습니다. 독립 재생성 결과 **전체 9,869개 객체**의 구조·형상·재질·동작·속성과 장면 설정이 일치했습니다.

기존 회귀 검사 **24개 중 23개 통과**, 아래에 명시한 원본의 P01 케이블 오류 1건은 동일하게 실패합니다. 원본 대비 새 회귀 실패는 없습니다. 최종 검토에서 발견된 팔레트/보, 바퀴/받침목 간섭은 실패 테스트로 재현한 뒤 수정했으며, 수정 후 전체 창고 검사를 다시 통과했습니다.

- 창고/운영 검사: `review/green-design-v008.log`
- 차량 구조물 간섭: `review/candidate-warehouse-v008-clearance.json`
- 창고 외 영역 보존: `review/candidate-warehouse-v008-preservation.json`
- 기존 24개 회귀 검사: `review/candidate-warehouse-v008-inherited-regression.json`
- 독립 재생성 비교: `review/reproduction.json`
- 독립 최종 검토 및 수정 판정: `review/final-review.md`

차량 검사는 US_FRAME 기준 개별 메시의 보수적 AABB를 사용합니다. 전체 타임라인 정수 프레임, 물류 구간의 반 프레임, 후진/후속 출발 구간의 1/8 프레임을 검사합니다. 바닥 접촉 허용 오차는 0.005입니다. 유한한 샘플 검사이며 모든 실수 시각에 대한 연속 충돌 증명은 아닙니다.

기존 `P01 cable 0 unsupported`는 원본에서도 재현되는 크레인 오류이며 이 창고 변경 범위 밖에 남겨 두었습니다. 작업자와 기존 차량 등은 기존 블록아웃 표현을 유지합니다. Cycles에서 기존 객체 일부가 흰색으로 보이는 것은 기존 셰이더 상태를 보존했기 때문입니다.
