# S1–S7 전체 배치 통합 마스터

사용자의 ‘전체 마스터에 통합해라’ 지시에 따라 S4-05 기준 제안 배치와 동선을 f0–1392 전체 영상으로 연결했다. 현재 작업 파일은 `master-full-layout-v001.blend`다.

## 통합 내용

중국 항만의 S1·S2는 원본 구도를 유지한다. S3에서 선박과 화물의 적재 관계를 유지하면서 새 미국 항만 위치로 항로와 카메라를 연결한다. 선박이 구면 바다 위에 계속 떠 있도록 항만 전체에 공통 회전·이동을 적용했으며, 제안본의 미국 항만 내부 배치·카메라 관계는 유지한다.

S4 인양에서는 컨테이너가 원래 선박 적재 칸을 지킨다. f532부터 올라가고, 주변 컨테이너 위로 벗어난 f542부터 수평으로 옮겨 f552의 채택된 경로에 연결된다. 인양 장치·트롤리·케이블도 같은 위치를 따른다. f552–948의 제안 구도와 차량 동작은 미국 항만 좌표계에서 유지된다.

S6의 화물 입고·보관·피킹·포장·상차와 S7의 출고 차량을 재배치된 창고와 도로에 연결했다. 문 개방 811–842, 후진 849–890, 첫 출고 1201, 두 번째 출고 1261의 기존 시각을 유지한다. 승인된 차량·컨테이너·문·도크 형상도 유지한다.

바퀴의 접지는 통합된 도로 위에서 출발 이후 1/16프레임 간격으로 다시 계산했다. 카메라가 f648 전후 잠깐 유지되는 것은 채택된 출발 구도의 의도된 정지이며, 이후 차량을 따라 이동한다.

## 검증과 출처

원본: `../s5-integration-v001/master-s5-integration-v001.blend`, SHA `8c76f0e184bc742309cf66dcf9f3f5fa7072e02b54b58e6985a91ff1ae57b665`.

채택 제안본: `../../storyboard/s5-sync-v001/layout-proposal-v001/s4-s5-layout-proposal-v001.blend`, SHA `c9efed5cabde76926b340732191ef8470986a5b36b2095f1a416f2064a2c4296`.

최신 마스터 해시는 `build-record.json`, 렌더 출처는 `render-full.json`, 영상 출처는 `package-record.json`에 기록한다. 저장한 마스터를 별도 Blender 프로세스에서 다시 열어 검증·렌더한다.

- `review/full-acceptance.json`: 전체 범위, 후속 동작, 카메라 연속성, 선박 수면 접촉.
- `review/master-regression.json`: 23개 기존 동작 검사. 옛 창고의 고정 좌표 검사만 실제 메시 충돌 검사로 대체하고, 채택된 f648 정지를 허용하면서 추적 재개를 검사한다.
- `logs/wheel-tests.log`: 5개 차량 검사, 출발 이후 1/16프레임 접지 검사 포함.
- `review/layout-acceptance.json`: 채택 구도·문·접안·형상 검사 14개.
- `review/preservation.json`: S1·S2의 71개 관련 객체와 카메라 보존, 제안 구간의 273개 객체와 카메라 관계 보존, 차량·컨테이너 메시 불변.
- `review/handoffs.json`: 항로·인양 연결에서 선박 적재물 충돌, 인양 장치 정렬, 카메라 거리 검사.
- `review/space-validation.json`: f720–948 실제 차량·문·창고·도크 메시의 0.25프레임 충돌 검사(1,650,704쌍, 금지 관통 0건).

전체 프리뷰는 f0–1392를 12fps로 렌더한 1,393프레임, 116.083333초다. 연결부 영상은 f408–1032다. 독립 최종 검토에서 Critical/Important 지적은 없었다. 직접 재개방과 1,393개 렌더 해시도 확인했다. 브라우저 원속도 재생 결과는 `review/playback.json`에 기록한다.

## 남은 연출 사항

채택된 제안본과 같이 f692–700에 크레인 기둥이 차량 일부를 잠깐 가린다. 현재 블록아웃의 선박·창고 세부 형상은 스토리보드의 상세 그림과 다르다. 이 통합으로 기존 스토리보드 PNG나 선화 후보를 자동 확정하지 않았다.

## 재생성

빌드·검증·렌더·패키지 스크립트는 `../../storyboard/s5-sync-v001/scripts/`에 있다: `integrate_full_master.py`, `run_full_regression.py`, `verify_full_preservation.py`, `check_full_handoffs.py`, `render_full_master.py`, `package_full_master.py`. 신규 검사 `tests/full_master.py`도 같은 상위 폴더에 있다. 입력 파일을 보존하고 새 전체 마스터를 저장한다.
