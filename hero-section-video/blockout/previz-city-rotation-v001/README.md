# PNPLINE 최신 채택 프리비즈 — 도시 회전 v001

2026-10-29 사용자 지시 “도시 회전안을 채택한다.”에 따라 도시 회전 v002를 S1–S7 최신 프리비즈 기준으로 승격했습니다.

**작업 파일: master-previz-city-rotation-v001.blend**

선택된 후보에 이미 전체 S1–S7이 들어 있으므로 전체 장면을 새 이름으로 저장했습니다. 객체 중복 추가나 B안 항로·미국 이동은 적용하지 않았습니다. 원래 12fps, f0–1392, S1–S7 마커, 선박 항로·미국 배치·하역/차량/창고 동작을 유지합니다. 중국 180° 회전, 크레인 재연결, S1 카메라 f0–72 보존, f73–339의 공개/항해 카메라 연결을 포함합니다.

기존 master-previz-styleframe-v001.blend와 후보 파일, 기존 Blender의 미저장 창은 보존했습니다. 이 채택본은 사용자가 검토한 디스크 후보가 기준이며 다른 창의 미저장 변경을 포함하지 않습니다. 커밋·push는 하지 않았습니다.

## 검증 범위

delivery.json에 원본·새 마스터 해시를 기록합니다. scripts/verify.py는 저장본을 새 프로세스에서 열어 모든 객체/Action 데이터와 객체별 Action·slot 연결, 컬렉션, 시간축, 전체 정수 프레임의 애니메이션 객체 월드 변환 및 렌즈를 후보와 비교합니다. verification.json의 결과는 채택 과정에서 데이터가 달라지지 않았다는 뜻입니다. 새 마스터에서 f156 대표 렌더도 다시 출력합니다.
