# PNPLINE 중국 홈페이지 컨셉 디자인

제작일: 2026-09-15
산출물: 하나의 홈페이지를 구성하는 가로형 섹션 PNG 10장. 서로 다른 대안 10개가 아닙니다.

## 참고 자료

- 시각 참고: https://www.fulfilmentcrowd.com/
- 콘텐츠: docs/pnpline-china-source-content/pnpline-home-a-content-brief-v3.md
- 로고: 사용자가 첨부한 공식 PNPLINE 로고. resources/logo/PNP-LINE.webp와 동일한 디자인입니다.
- 브랜드 토큰: output/design-concept-v1/design-tokens.css
- 사용자 지정 스킬: imagegen-frontend-web. 섹션마다 독립된 가로형 이미지를 생성했습니다.

첨부 콘텐츠 문서는 화면 원고와 사업 정보의 참고자료로 사용했습니다. 문서 안의 과거 이슈, 승인 절차, 구현 작업 지시는 이번 사용자 요청으로 간주하지 않았습니다. 실제 사이트 구현이나 게시 작업은 수행하지 않았습니다.

## 참고 사이트 분석과 적용

| 요소 | 실제 참고 사이트에서 확인한 특징 | PNPLINE 적용 |
| --- | --- | --- |
| 히어로 | 창고 작업 영상이 화면을 채우고 어두운 오버레이 위에 중앙 제목과 CTA를 배치 | 물류 현장 컨셉 이미지, 중앙 중국어 제목, 직영창고와 주문 이행 메시지 |
| 색상 | 흰색·옅은 회보라색 바탕, 짙은 자주색 텍스트, 마젠타 강조 | 흰색·옅은 청록색 바탕, 잉크색 텍스트, 공식 로고의 청록색 강조 |
| 레이아웃 | 넓은 콘텐츠 폭과 여백, 중앙 섹션 제목, 이미지와 설명을 병렬 배치 | 고객 카드, 서비스 탭, 과정 도식, 비용 행 목록 등 목적별 구성 |
| 카드 | 밝고 옅은 면색, 절제된 둥근 모서리, 사진 영역과 설명 영역 구분 | 3개 고객 카드와 2개 문의 예시 카드, 8px 반경을 목표로 지정 |
| 탭 | 가로 메뉴 아래 얇은 선으로 활성 상태 표시 | 4개 핵심 서비스 탭, 첫 번째 일건 배송 서비스를 펼친 상태 |
| 타이포그래피 | 브라우저 계산 스타일: Google Sans / Product Sans / Arial. H1 70px·500, H2 42px·400, H3 30px·400 | 중국어 Noto Sans SC와 라틴 Inter를 기준으로 크기 위계 설정. 이미지 생성 결과의 글꼴·굵기는 근사 표현 |
| 버튼 | 단순한 사각형 버튼과 화살표 링크, 명확한 주 행동 | 청록색 견적·제출 버튼과 보조 밑줄 링크 |

측정한 글꼴 값은 1440px 브라우저 화면의 CSS 계산값입니다. 생성된 이미지의 실제 글꼴 파일이나 픽셀 단위 치수를 검증한 것은 아닙니다.

## 공통 디자인 방향

- 컨셉: 중국 출고부터 미국 직영창고와 주문 배송까지 이해할 수 있는 물류 홈페이지.
- 브랜드 강조색 #00ABE1, 주 행동색 #007FA8, 본문 잉크색 #182C39.
- 흰색 #FFFFFF, 옅은 청록색 #F3FBFE 및 #DFF6FD를 밝은 바탕으로 사용.
- 밝은 정보 섹션 사이에 짙은 운영·시스템 섹션을 배치해 시각적 리듬 형성.
- 가로형 1440×900 비율을 생성 목표로 지정했으며 실제 파일 크기는 각 PNG에 기록된 해상도를 따릅니다.

## 컨셉 해석

- 모든 창고·작업자·상자·문서 사진 및 시스템 UI는 생성한 시각 컨셉이며 실제 시설·직원·시스템의 증빙이 아닙니다. 화면에 概念示意를 표시했습니다.
- 미국 창고를 직접 운영한다는 내용은 제공된 V3 콘텐츠를 반영했습니다.
- 20 CBM와 월 500건은 실제 실적이나 가격이 아니라 문의 조건 예시입니다.
- 서비스 탭, FAQ, 문의 폼은 정적 화면 디자인입니다. 실제 작동하거나 문의가 제출되는 결과물이 아닙니다.
- 생성형 이미지 특성상 중국어 세부 글자, 원본 로고의 곡선, 자간 및 행간은 후속 편집 가능한 디자인 제작 시 원문·원본 자산으로 정밀하게 맞춰야 합니다.
