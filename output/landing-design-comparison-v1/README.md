# PNPLINE 디자인 A/B 비교

수정된 중문 V4의 히어로·서비스·견적 영역을 구현한 비교 시안이다. 사용자는 2026-10-31 기존 제품 기준과 코드 우선 제작을 확인했다. 제품 기록은 프로젝트 루트 `PRODUCT.md`에 있다. 두 시안 중 최종 방향은 아직 선택하지 않았다.

## 열기

```powershell
python -u output/landing-design-comparison-v1/server.py
```

출력된 127.0.0.1 주소를 브라우저에서 연다. 서버는 이 폴더만 제공하며 MP4의 Range 요청을 지원한다. 서버 프로세스가 실행 중이어야 한다.

- `index.html`: A/B 데스크톱 1440×900과 모바일 390×844를 함께 보여 주는 비교 화면.
- `a.html`: 밝은 파노라마 히어로, 창고 작업을 먼저 펼치는 서비스 구성, 밝은 배경의 견적 폼.
- `b.html`: 화면 전체 영상과 짙은 본문, 행으로 구분한 서비스, 배경에 통합한 견적 폼.
- `privacy.html`: 개인정보 전문이 아직 작성·검수되지 않았음을 설명하는 경로 확인용 안내. 운영 경로 `/privacy/`를 대신하는 승인된 정책이 아니다.

## 비교 도구

상단에서 데스크톱·모바일·동시 보기를 선택한다. 히어로·서비스·견적 버튼은 네 화면을 같은 영역으로 이동한다. 영상 시점 슬라이더나 0/50/100% 버튼으로 같은 시점을 비교할 수 있다. 각 프레임 안에서도 직접 스크롤할 수 있다. ‘크게 열기’는 해당 시안의 실제 페이지를 연다.

‘긴 스크롤 구간 접기’는 전체 배치 검토용이다. 이 모드에서는 히어로를 일반 화면 높이로 접는다. 직접 페이지 URL에 `?overview=1`을 붙여도 사용할 수 있다. 기본 페이지에서는 실제 긴 스크롤 구간과 sticky 영상 시점 제어가 작동한다.

## 콘텐츠와 기능

`build.py`는 최신 `docs/pnpline-china-source-content/pnpline-landing-mvp-copy-v4.zh-CN.md`를 읽어 A/B에 같은 텍스트를 넣는다. 수정 후 다시 생성할 때는 다음을 실행한다.

```powershell
python output/landing-design-comparison-v1/build.py
```

CSS·JS와 비교 화면은 생성기에 덮어쓰이지 않는다. 원고 해시와 미디어 출처는 `content-manifest.json`에 있다.

- 스크롤 위치를 0~1로 계산해 실제 영상 길이에 곱한다. 역스크롤과 정지 상태에서도 동작한다.
- 자동 재생·반복 재생·재생 버튼은 사용하지 않는다.
- 모션 감소 설정과 영상 오류에서는 긴 스크롤 구간을 제거하고 대표 이미지·본문·문의 접근을 유지한다.
- 견적 폼은 6개 항목과 개인정보 동의 배치를 검토한다. 제출 시 ‘设计预览：信息未发送。’를 표시하며 외부로 전송하지 않는다.
- 사용자 삭제 문구와 장면 설명표를 다시 넣지 않았다. 미확인 시설·실적·자격·요율을 추가하지 않았다.

## 미디어와 글꼴

공통 영상은 기존 33초 작업본 `hero-section-video/blockout/pacing-33s-v001/preview/pnpline-33s-30fps-v001.mp4`에서 시킹 검토용으로 재인코딩했다. 1280×720, 30fps, H.264, GOP 6, faststart다. 원본 파일은 수정하지 않았다. 최종 영상 선정이나 완성 영상의 성능 검증을 의미하지 않는다.

포스터는 같은 영상의 3.5초 프레임이다. 로고는 기존 `resources/logo/PNP-LINE.webp`다. 출처는 포스터의 내장 메타데이터 및 로고의 `.json` 사이드카에 기록했다. `embed-prompt --scan assets` 결과 참조 래스터 2개 모두 출처를 보유한다.

Noto Sans SC는 Google Fonts에서 원고에 필요한 글자만 내려받아 로컬 파일로 제공한다. 네 굵기와 OFL 라이선스가 `assets/`에 있다. 실행 시 외부 폰트 서버나 라이브러리에 연결하지 않는다.

## 확인 범위

1440×900 및 390×844에서 두 시안 전체를 캡처했고, 320×568에서 가로 넘침과 CTA 위치를 추가 확인했다. 네 프레임 모두 0/50/100/50%에서 영상 0/약16.50/32.999/약16.50초, paused=true를 확인했다. 실제 휠 정방향·역방향, 서비스·견적 앵커, 전송하지 않는 제출 상태도 확인했다.

검증 기록과 전체 화면 캡처는 프로젝트 `.impeccable/review/`에 있다. 모바일은 브라우저 화면 크기를 변경한 검증이며 실제 iOS/Android 기기의 터치·디코딩 성능 검증은 남아 있다.
