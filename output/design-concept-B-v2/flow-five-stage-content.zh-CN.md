# S2 중국→미국 5단계 물류 흐름

- Eyebrow: `物流全流程`
- H2: `看清货物从中国到美国的每一步`
- 본문: `从出货资料到美国境内配送，先确认各阶段需要衔接的工作。`

| 단계 | 제목 | 설명 |
| --- | --- | --- |
| 01 | `中国工厂` | `整理商品、包装与出货资料。` |
| 02 | `头程运输` | `根据货量与时效需求，评估整柜、拼箱或空运。` |
| 03 | `美国清关` | `核对申报资料、IOR需求与各方责任。` |
| 04 | `美国自营海外仓` | `衔接入库验收、库存管理与出库作业。` |
| 05 | `美国境内配送` | `按需求对接FBA补货、订单配送或B2B交付。` |

- 보조 문구: `具体路线、服务范围与时效，以确认后的物流方案为准。`
- 개념 표시: `图片为概念示意 · 非实际设施影像`

직영 운영으로 확정된 것은 미국 창고 단계다. 다른 단계까지 모두 PNPLINE이 직접 수행한다는 의미로 확대하지 않는다.
