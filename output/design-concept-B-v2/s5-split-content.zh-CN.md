# S5 분리 섹션 화면 문구

첨부 브리프의 S5를 서로 다른 근거 유형에 따라 두 개의 가로형 섹션으로 분리했다.

## S5-A/B — 직영창고·책임 근거

- Eyebrow: `运营依据`
- H2: `先看自营仓库，再确认服务责任`
- 본문: `了解实际作业场地、服务责任与库存管理方式，再评估适合您的合作方案。`
- 블록 1: `美国自营仓与作业范围`
- 설명: `PNPLINE直接运营美国仓库。了解仓内作业内容、受理条件与可核验的运营资料。`
- 링크: `了解仓储服务 ↗`
- 블록 2: `IOR、Bond与服务责任`
- 설명: `确认进口过程中各方承担的工作、所需文件，以及可核验的资质与合规资料。`
- 링크: `了解IOR服务范围 ↗` / `查看资质与合规资料 ↗`
- 개념 표시: `结构示意 · 非实际设施资料`
- 고지: `设施细节、资质与责任范围，以审核后公开资料为准。`

## S5-C — WMS 시스템

- Eyebrow: `系统能力`
- H2: `从库存查询，到出库指令`
- 본문: `了解库存、入库记录、订单状态与出库进度的管理方式。`
- 기능 후보: `库存查询` / `入库记录` / `出库指令` / `订单与作业状态` / `出库历史`
- 링크: `了解WMS功能 ↗` / `查看API与ERP对接范围 ↗`
- 개념 표시: `概念示意 · 非实际系统截图`
- 고지: `可用功能、账号权限和数据更新方式，以实际系统为准。`

시설명·주소·면적·처리 수치·실적·인증 배지·IOR 또는 Bond 보유 주장은 넣지 않았다. 직영 운영만 사용자 확인 사항으로 유지하며, 청사진과 WMS UI는 모두 개념 표현이다.
