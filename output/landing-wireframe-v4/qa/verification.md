# 브라우저 검증 기록

검증일: 2026-10-31

미리보기: `http://127.0.0.1:12110/index.html`. 로컬 서버 실행 중에 접근할 수 있다. 서버 루트는 `output/landing-wireframe-v4`만 제공하며 127.0.0.1에 바인딩했다. 원래 선택한 8765 포트가 운영체제에서 거부되어 사용 가능한 포트를 할당받았다.

브라우저: Codex 인앱 브라우저. 데스크톱 기준 1440×900, 모바일·태블릿은 브라우저 viewport 변경으로 검사했다.

## 히어로

기존 `hero-section-video/blockout/pacing-33s-v001/preview/pnpline-33s-30fps-v001.mp4`를 검토 패널의 파일 선택으로 연결했다. 이 영상은 동작 확인에 사용한 작업본이며 최종 영상으로 선정·교체한 것이 아니다. 브라우저 내부 blob URL로만 사용하며 업로드하지 않는다. 새로고침하면 다시 선택해야 한다.

| 스크롤 위치 | 실제 video.currentTime | paused |
| --- | --- | --- |
| 0% | 0.000000초 | true |
| 25% | 8.254220초 | true |
| 50% | 16.499500초 | true |
| 75% | 24.753721초 | true |
| 100% | 32.999000초 | true |
| 25%로 역이동 | 8.254220초 | true |

픽셀 단위 스크롤 반올림과 종료 시점의 0.001초 제한 때문에 소수점 차이가 있다. 각 위치에서 히어로 상단은 120px로 유지됐다. 역이동 후 다음 관찰에서도 8.254220초와 paused=true를 유지했다.

제작 패널 버튼 외에 실제 스크롤 입력으로 아래 이동 시 43% / 14.290624초, 위 이동 시 34% / 11.276894초로 바뀌는 것을 확인했다. 390×844 화면에서도 스크롤 입력 후 18% / 6.038845초, paused=true, 히어로 상단 112px를 확인했다.

## 레이아웃과 조작

- 320×568, 375×667, 390×844, 768×1024, 1024×768, 1440×900에서 문서 scrollWidth와 clientWidth가 같았다. 페이지 가로 넘침은 없었다.
- 320·375·390px에서는 서비스 카드와 폼이 1열, 768px 이상에서는 2열이다.
- 서비스·견적 CTA를 클릭하면 같은 페이지의 해당 섹션이 고정 헤더 아래에 도착했다. 390px에서 각 섹션 상단은 약 112px였다.
- 모바일 FAQ 첫 질문의 펼침, 개인정보 안내 대화상자 열기·닫기를 확인했다.
- 모바일 검토 패널을 열고 섹션을 클릭하면 패널이 닫히고 버튼 문구·aria-pressed가 실제 상태와 일치했다.
- 잘못된 미디어 파일을 선택하면 영상이 숨겨지고 도식과 오류 안내가 나타났다. 이후 정상 MP4를 다시 연결해 50% 시킹에 성공했다.
- 최종 확인 시 브라우저 개발 로그의 error/warn은 없었다.

## 수정 사항

1. 화면 크기가 달라질 때 패널 버튼 문구가 갱신되지 않던 문제를 해결했다. 패널 링크로 닫을 때도 상태를 동기화한다.
2. 1024px 이하에서는 검토 패널을 겹쳐 여는 방식으로 바꿔 태블릿에서 본문이 지나치게 좁아지는 것을 방지했다.
3. 월 출고량 안내가 긴 placeholder에서 잘리던 문제를 해결했다. 원고의 안내를 필드 아래 줄바꿈 텍스트로 옮기고 aria-describedby로 연결했다.
4. 고정 헤더를 불투명하게 해 스크롤된 본문이 헤더 뒤로 비치지 않도록 했다.

## 검증 자료와 한계

- `seek-checks.json`: 위치별 영상 시점 원자료.
- `layout-checks.json`: 화면 크기별 가로 폭·열 수·패널 상태.
- `mobile-seek.json`: 모바일 스크롤 관찰값.
- `desktop-hero-50.jpg`, `mobile-hero-390.jpg`, `mobile-services-390.jpg`, `mobile-quote-390.jpg`, `mobile-faq-390.jpg`: 실제 브라우저 화면 캡처.

실제 iOS/Android 기기, 터치 제스처, 최종 렌더 영상의 시킹 성능, 운영체제 모션 감소 설정 변경은 이번 검증 범위에 포함하지 않았다. 폼은 전송 서버에 연결되지 않은 검토용이다.
