# PNPLINE 중문 V4 랜딩 와이어프레임

2026-10-31 · 수정된 중문 원고 기반 · 로컬 검토용

`standalone.html`을 브라우저에서 열면 스크롤 가능한 와이어프레임을 확인할 수 있다. 이 파일 하나에 CSS·JS를 포함해 공유할 수 있다. 편집용 파일은 `index.html`, `wireframe.css`, `wireframe.js`다. 별도 설치나 서버가 필요하지 않으며 외부 폰트·라이브러리·네트워크 요청을 사용하지 않는다. `overview.png`는 전체 배치를 요약한 별도 구조 검토 이미지다. 브라우저 화면을 캡처한 이미지는 아니다.

## 구성과 원고

원본은 `docs/pnpline-china-source-content/pnpline-landing-mvp-copy-v4.zh-CN.md`다. 원고를 수정하지 않고 읽어서 와이어프레임을 생성했다. 삭제된 스크롤 유도 문장과 콘셉트 표식을 다시 넣지 않았다.

| 순서 | 앵커 | 와이어프레임 표현 |
| --- | --- | --- |
| 히어로 | journey | 화면 고정 영상 영역 + H1·보조 설명·CTA |
| 서비스 | services | 창고·주문 이행을 큰 카드로, 운송·통관·시스템을 옆에 배치 |
| 고객 | customers | 판매 유형별 요구 비교표 |
| 운영 | evidence | 창고 인계 / 재고·출고 관리의 2열 텍스트 |
| 상담 절차 | process | 요구 전달 → 조건 확인 → 견적 확인의 3단계 |
| 비용 | pricing | 5개 비용 항목과 확인 조건 |
| FAQ | faq | 8개 질문을 펼치는 아코디언 |
| 견적 | quote | 원고의 6개 필드 + 개인정보 동의 + 단일 제출 버튼 |

헤더와 본문 CTA는 같은 페이지의 앵커로 이동한다. 개인정보 링크의 목표는 `/privacy/`이며, 이 검토본에서는 미작성 정책을 대신하지 않도록 안내 대화상자를 연다. 실제 창고 사진·수치·인증 배지·WMS 화면은 추가하지 않았다. 폼은 입력 배치 검토용으로 서버에 제출하지 않으며 접수 성공 메시지를 표시하지 않는다. 필수값·동의·전송 검증은 운영안 확정 후 구현한다.

## 히어로 동작

히어로 섹션에 스크롤 구간을 두고 내부 미디어와 문구를 sticky로 고정했다. 현재 360vh는 검토용 길이이며 제작 확정값이 아니다.

```
고정 시작점 S = 히어로 문서 위치 - 상단 고정 UI 높이
스크롤 구간 D = 히어로 높이 - 고정 화면 높이
진행도 p = clamp((scrollY - S) / D, 0, 1)
영상 시점 t = p × 영상 길이 T
```

- 아래로 스크롤하면 뒤 시점으로, 위로 스크롤하면 앞 시점으로 이동한다. 멈추면 시점을 유지한다. 재생 버튼·자동 재생·반복 재생은 없다.
- 영상이 없는 기본 상태에서는 화물 위치와 카메라 각도가 스크롤 진행도에 대응하는 회색 도식으로 표현된다. 이는 최종 장면이나 완성 영상의 품질 검토가 아니다.
- 검토 패널의 ‘작업 영상 연결’에서 로컬 영상을 선택하면 `video.currentTime`을 스크롤에 맞춘다. 영상은 업로드되지 않는다. 영상 종점은 디코딩을 위해 duration보다 0.001초 앞에서 제한한다.
- 시킹 중에는 최신 목표 위치를 기억하고 seeked 이후 반영한다. 일정 시간마다 영상이 진행되는 타이머는 없다.
- 검토 패널의 0/25/50/75/100% 버튼은 스크롤 위치를 이동해 매핑을 확인하는 제작 도구다. 공개 UI에 들어갈 타임라인·장면 선택 버튼이 아니다.
- S1–S7의 명칭과 설명은 제작 패널에만 있다. 구간별 초·프레임·스크롤 비중은 최종 미디어 명세가 필요하다. 7개 동일 구간으로 확정하지 않았다.
- 히어로 중간에서도 CTA로 서비스·견적에 바로 이동할 수 있다. 끝까지 스크롤할 필요가 없다.
- 모션 감소 설정에서는 정적인 첫 장면을 표시하고 긴 히어로 스크롤 구간을 없앤다. 선택한 영상에 오류가 나면 기본 도식과 본문 접근을 유지한다.
- 작업 영상의 코덱과 키프레임 구조에 따라 시킹 지연이 달라질 수 있다. 최종 영상·실기기 검증은 별도다.

## 검토 도구와 반응형

상단 ‘전체 구조’는 긴 히어로 구간을 접어 전체 섹션 구성을 살펴보는 모드다. ‘검토 패널 숨기기’는 제작 패널과 청색 주석을 숨긴다. 작은 화면에서는 검토 패널을 버튼으로 열고 닫는다. 서비스 카드·절차·폼은 1열로 바뀌고, 헤더는 브랜드와 견적 CTA로 줄어든다.

## 생성과 확인

`python output/landing-wireframe-v4/build.py`로 최신 중문 원고에서 HTML을 재생성할 수 있다. CSS와 JS는 별도 파일이며 빌드에 덮어쓰이지 않는다. `python output/landing-wireframe-v4/make-overview.py`는 구조 검토 이미지를 생성한다.

정적 점검 범위: 8개 섹션·내부 링크 대상·6개 폼 필드·8개 FAQ·삭제 문구 부재·외부 리소스 부재·JS 구문.

2026-10-31 추가 검증에서는 로컬 HTTP 서버로 브라우저를 열어 실제 33초 작업 영상의 스크롤 시점 이동과 반응형 배치를 확인했다. 320·375·390·768·1024·1440px 폭에서 문서 가로 넘침이 없었으며, 모바일 패널 상태와 잘리는 폼 안내를 수정했다. 자세한 결과와 실제 화면 캡처는 [QA 기록](qa/verification.md)에 있다. 브라우저의 화면 크기를 변경한 검증이며 모바일 실기기 검수는 아니다.
