# PNPLINE 1920 콘셉트 리뷰

8개 영역을 각각 별도의 가로형 이미지로 검토하는 갤러리다. 실제 랜딩 구현을 교체하지 않으며, 이미지 속 메뉴·스크롤·FAQ·폼이 동작한다는 뜻은 아니다.

## 디자인 기준

- 전체 디자인 캔버스 폭: **1920px**.
- 본문 최대 폭: **1440px**. 1920px 기준 좌우 여백은 각각 **240px**, 콘텐츠 경계는 x=240과 x=1680이다.
- 히어로 영상은 콘텐츠 폭 제한 없이 전체 1920px 폭을 사용한다. 콘셉트는 영상의 한 프레임으로 구도를 보여준다. 실제 정방향·역방향·정지 프레임 제어는 후속 구현의 동작 요구다.
- 밝은 본문 바탕, 공식 청록색, 중문 산세리프, 직각 버튼·입력 윤곽을 공통 기준으로 삼는다.
- 확인되지 않은 시설·시스템·운영 자료 대신 `IMAGE` 자리표시자를 유지한다. 실제 운영 실적이나 인증을 만들어 넣지 않는다.
- 원본 이미지의 실제 픽셀 크기는 최종 생성 매니페스트와 갤러리의 로딩 결과를 기준으로 확인한다. 1920px이라는 디자인 기준을 원본 파일의 실제 해상도라고 단정하지 않는다.

## 갤러리

`index.html`을 로컬 서버로 열면 된다. `화면에 맞추기`는 전체 구도를 축소해서 보여주고, `1920px 보기`는 이미지 표시 폭을 1920 CSS px로 고정한다. 후자는 화면이 좁으면 각 이미지 영역에서 가로로 스크롤한다.

`본문 1440px 가이드`는 본문 이미지의 12.5%와 87.5% 지점에 검토용 선을 겹쳐 보여준다. 원본 파일을 변경하지 않으며, 전체 폭 예외인 히어로에는 선을 표시하지 않는다. 각 이미지의 원본 보기와 다운로드 링크도 제공한다.

| 영역 | 이미지 파일 |
| --- | --- |
| 히어로 | `images/01-hero.png` |
| 서비스 | `images/02-services.png` |
| 고객 유형 | `images/03-customers.png` |
| 창고와 시스템 | `images/04-evidence.png` |
| 진행 절차 | `images/05-process.png` |
| 비용 설명 | `images/06-pricing.png` |
| FAQ | `images/07-faq.png` |
| 견적 문의·푸터 | `images/08-quote.png` |

한 장의 긴 합성 이미지로 만들지 않고 영역별 결과를 그대로 표시한다. 생성 파일이 아직 없으면 해당 영역에 준비 중 안내가 표시된다.
