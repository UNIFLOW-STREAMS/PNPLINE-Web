# 브라우저 QA 실행 전 검사 목록

- 1440×900 / 390×844 / 360×800 초기 화면과 가로 넘침.
- 각 뷰포트의 6장면 이미지 디코딩, 별도 가로/세로 구성 전환.
- 12개 프레임의 카피·CTA 허용 영역과 실제 내용 높이, 로고·공정·경로 마스크.
- 카피 on/off, 안전영역 on/off, 모든 장면 정적 접근.
- range 방향키·Home·End, 명확한 포커스, 진행·장면·가상 시간 표시.
- 5개 경계 앞뒤의 불투명 전경 가림, animatic 카피·마스크 전환.
- 휠의 기본 문서 이동, 모바일 반응형.
- 모션 감소 실시간 전환 후 이동·줌·페이드 제거와 6개 정적 콘텐츠.
- 예외 1: 실제 이미지 요청 실패 시 안내·단계 설명.
- 예외 2: 모션 감소 상태에서 progress 변경과 표준 콘텐츠 접근.
- 콘솔·JavaScript 오류 및 내부 링크 HTTP 상태.
- 기능 검사와 별도로 캡처를 직접 열어 구도·중국어 줄바꿈·로고 가림을 시각 검토.

실제 iOS·Android 기기, 영상 재생·시킹 성능, 실기기 fps는 이 검사 범위가 아니다.
