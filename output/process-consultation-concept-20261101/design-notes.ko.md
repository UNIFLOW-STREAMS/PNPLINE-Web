# Process 상담 절차 재구성 컨셉
2026-11-01

## 판단
현재 첫 두 단계(요구 전달·계획 확인)의 의미를 유지·보완해 3단계 상담 절차로 합친다. 기존 입고·준비와 미국 출고를 설명하는 마지막 두 단계는 이 섹션에서 견적 확인 단계로 대체한다. 물류 운영 설명은 이미 Services와 Warehouse에 존재한다.
새 공개 페이지나 추가 프로세스를 만들지 않고 기존 #process 위치에서 교체하는 제안이다. 이번 작업은 별도 컨셉 산출물이며 현재 Next.js 소스는 수정하지 않았다.

## 원고 대응
근거는 docs/pnpline-china-source-content/pnpline-landing-mvp-copy-v4.zh-CN.md 87–91행.
01 Share requirements — 상품, 운송 방식, 예상 물량, 목적지, IOR 요구를 설명하고 미정 항목을 표시.
02 Review conditions — 수리 범위, 서류, 창고 작업, 납품 요구와 책임 분담 확인.
03 Confirm the quote — 계산 단위, 포함 항목, 추가 비용, 실행 조건을 확인한 뒤 다음 인계.
기존 origin 정보는 01 상세 질문이나 문의 폼에 유지할 수 있다. 실제 물류 진행 상태나 상담 완료를 이 단계 표시에서 주장하지 않는다.
영문은 현재 사이트와 맞췄다. 검토용 콘텐츠 전체는 content.json.

## 구성 도구
공통 기준선이 있는 3단계 stepper와 단일 상세 패널. 요약 3개는 항상 표시한다.
03 선택 상태를 이미지로 제시해 기존에 누락된 견적 확인 내용을 강조했다. 상세 패널 안 2×2 체크항목은 계산 단위·포함항목·추가 비용·실행 조건.
Pricing의 비용 종류 표와 역할이 다르다. Process는 견적을 확인하는 절차, Pricing은 항목별 비용 조건을 설명한다.
설명형 미니어처(브리프·체크리스트·견적서)와 서류·작업조건·견적검토 선 아이콘을 쓴다.

## 인터랙션
실제 사이트 적용 시 기본 선택은 01. 시안 및 현재 HTML 스터디는 보완 항목 검토를 위해 03을 기본 표시한다.
클릭/Enter/Space 또는 방향키/Home/End로 선택한 상세를 표시. 탭의 aria-selected와 단일 패널 제목을 함께 갱신.
공통 패널 내용은 opacity와 y4px를 200ms에 걸쳐 전환한다. 이동/선택 피드백과 상담 완료를 구분한다. 완료 체크·진행률 백분율을 쓰지 않는다.
스크롤은 안내 경로의 진입 강조에만 사용할 수 있다. 읽는 중 상세 항목을 자동 교체하지 않는다.
모션 감소 설정은 즉시 교체하고 모든 요약을 유지한다.
CTA는 기존 #quote. '미정 가능' 안내는 기본 본문으로 유지하며 질문에 답해야 다음 단계를 볼 수 있게 잠그지 않는다.

White / #F4F6F7 / #172126 / #00ABE1, 얇은 선, 기존 작은 모서리.
이미지는 시각 방향이며 개발 수치는 이 가이드를 우선한다.
