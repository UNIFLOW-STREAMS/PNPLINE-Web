PNPLINE Design System V1

검수 전용 페이지

06 · Review Notes

검수 메모

명세의 출처와 결정 상태를 섞지 않도록 네 범주로 분리했습니다. 이 항목들은 승인 전에 문서 또는 토큰 차원에서 정리해야 합니다.

문서와 토큰의 불일치

  • 현재 확인된 색상값과 컴포넌트 높이의 직접적인 수치 충돌은 없습니다.
  • 문서는 Primary의 Hover/Focus를 모두 잉크 배경으로 설명하지만 CSS는 --action-primary-hover만 제공하고 Focus 전용 배경 토큰은 없습니다. 프리뷰는 문서 설명과 hover 토큰을 함께 적용했습니다.
  • 문서의 데스크톱 좌우 최소 여백은 40px이고 모바일은 16px입니다. 토큰 파일에는 전용 레이아웃 여백 토큰이 없습니다.

문서에만 정의된 항목

  • Display, H1, H2, H3, Body, Small, Label의 크기·행간·굵기 전체가 문서에만 있습니다.
  • 버튼 상태 설명, Evidence Badge 의미, FAQ 동작, 견적 폼 상태 흐름이 문서에만 있습니다.
  • 최소 터치 높이 44px은 문서와 버튼 토큰에 있으나 체크박스 자체 크기는 정의되지 않았습니다.

프리뷰에서 임시 해석한 항목

  • 버튼과 폼 컨트롤의 4px 반경, disabled·error 상태 색상, 체크박스 20px 크기를 기존 팔레트에서 최소한으로 조합했습니다.
  • Evidence Badge의 색상 매핑과 정보·성공·실패 안내 패널은 기존 신호색을 사용한 프리뷰 전용 해석입니다.
  • 정적 Hero의 업무 흐름 도식과 서비스 카드 그리드는 이미지 없이 레이아웃만 검수하기 위한 임시 구조입니다.

승인 전에 결정해야 할 항목

  • 타이포그래피를 CSS 토큰으로 승격할지와 실제 웹폰트 제공·로딩 정책을 결정해야 합니다.
  • 버튼·입력·배지의 component token, active 상태, 오류·disabled 색상과 반경을 확정해야 합니다.
  • focus ring이 어두운 배경에서도 충분한지, 고대비 대체 테두리가 필요한지 검수해야 합니다.
  • 실제 서비스별 Evidence Badge 상태와 공개 가능한 콘텐츠를 자료 검증 후 결정해야 합니다.

PNPLINE Design System V1 시각 검수 페이지 · 외부 네트워크 요청 없이 실행 가능 · 프리뷰 구현 완료는 디자인 승인 완료가 아닙니다.
