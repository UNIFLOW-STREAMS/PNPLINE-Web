- 색상: 네이비 #182C39, 초록 #19AE49, 세이지 #EFF5F1, 흰색 #FFFFFF.
- 폰트 방향: Noto Sans SC 계열 간체 중국어 고딕과 기하학적 라틴 산세리프.
- 히어로: 실제 Gardena·Katy 창고 사진을 화면 전체의 바탕으로 활용하고 `免费获取报价` CTA를 배치합니다. 현재 시안 이미지는 교체 대상입니다.
- 콘텐츠 순서: 가치 제안 → 서비스 선택 → 중국 공장부터 미국 소비자까지의 흐름 → 판매 채널 → 시스템 → 견적 상담.
- 주요 구성: 사진 아코디언, 사진 프레임, 과정 구분선, 시스템 화면과 출고 상세 패널.
- 여백이 많은 채널 섹션을 사진과 시스템 시안 사이에 넣어 정보 밀도를 조절했습니다.
- 구현 시 고려할 움직임: 사진의 완만한 이동과 서비스 아코디언 확장.

## 컨셉 표현과 검수

창고, 인물, 물품과 시설의 사진은 생성 이미지입니다. 실제 PNPLINE 시설을 촬영한 자료가 아닙니다. 중국 사이트 공개본, 특히 `自营仓库实景`과 홈 신뢰 영역에는 Gardena·Katy 현장 실사진, 실제 주소, 시설 수치, 법인·보험 증빙을 사용해야 합니다. WMS 화면도 원문에 기재된 기능을 바탕으로 새로 그린 예시입니다. 시안의 PNPLINE 타이포 로고와 포장 그래픽은 컨셉 표현이며 기존 공식 로고 에셋을 대체하는 확정안은 아닙니다.

물류망 초안은 지도 위치가 부정확해 최종본에서 지리 지도를 제거하고 중국 공장에서 출발해 미국 통관, 캘리포니아·텍사스 창고, 최종 소비자로 이어지는 업무 도식으로 바꿉니다. 이 그림은 실제 항공편, 운송 스케줄이나 정확한 창고 주소를 표시하지 않습니다.

배송 보장 수치, 수상 이력, 고객 추천사, 미확인 위챗 채널을 추가하지 않았습니다. Amazon·Shopify·TikTok Shop은 서비스 대상 채널로 표시했습니다. 중국 출발 구간·운송 방식은 실제 서비스 범위가 확인된 페이지에서만 구체적으로 표시합니다. 짧은 홈페이지 문의 폼은 상세 견적 페이지를 대체하는 확정 요구사항이 아닙니다.

섹션별 문구, 가로 비율, 서비스 경로와 팔레트를 시각 검수했습니다. 생성 이미지의 작은 글자·세부 표식은 실제 구현 시 검수된 중국어 텍스트와 공식 에셋으로 교체해야 합니다.
