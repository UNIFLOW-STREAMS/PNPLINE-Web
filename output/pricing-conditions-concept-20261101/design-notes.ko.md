# Pricing 컨셉 수정
2026-11-01

## 수정 판단
기존 보완 시안은 상단 좌우 패널, 패널 내부 비용 비교, 하단3열 체크가 같은 화면에 들어가 읽는 순서가 분산됐다.
이번 수정은 하나의 세로 읽기 흐름을 가진 신규2개 섹션으로 나눈다.
기존5행 Pricing 표 → 01 통관/IOR·비용명세 → 02 추가 과금조건 → 기존 FAQ의 순서다. 별도 공개URL을 만드는 제안은 아니다.

## 화면01
통관처리 범위, IOR 필요와 포함범위, 서비스비 별도표기, 적용 관세/세금과 포함여부를4개의 열린 세로행으로 읽는다.
서비스비/세금 항목에 작은 시안 마커를 적용해 별도 명세의 의미를 강조한다. 표 안의 표, 2중 패널, 가상 합계나 금액을 넣지 않는다.

## 화면02
최소 요금, 장기 보관, 특수 작업의 과금조건을3개의 넓은 세로행에 표시한다.
계산단위/최소요금 → 기간/계산기준/추가과금시점 → 포장/라벨/검품/반품 작업을 확인한다.
CTA는 마지막 화면 하단에1개, 기존 #quote로 연결한다. 확정 견적 기준 안내를 유지한다.

## 밀도와 시각 기준
각 화면은 제목1개, 짧은 도입1개, 일관된 행 목록1개를 사용한다. 주요 설명을 작게 줄이거나 hover 뒤에 숨기지 않는다.
정보행의 아이콘과 해당 제목/설명을 가깝게 묶는다. 미니어처는 문서 폴더/상자의 작은 보조 이미지로 제한한다.
1920px 본문1320px, 좌우300px, H2 44–56px, 본문18–20px, 아이콘32–44px. 세로간격과 실제섹션높이는 문장량에 맞춰 확보한다.
White / #F4F6F7 / #172126 / #00ABE1과 기존 Pricing의1px 구분선을 따른다. PNG의 픽셀 글자 크기를 실제CSS 수치로 역산하지 않는다.
모바일도 동일한 읽기순서로1열 배치한다.
