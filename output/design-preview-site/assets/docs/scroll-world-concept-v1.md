# #61 Scroll-world concept V1

## 2026-09-14 · V2 지리·카메라·미니어처 수정안

사용자의 후속 피드백에 따라 데스크톱 6장과 모바일 6장을 새로 제작했다. 중국 국기와 항만 배후 도시, 태평양을 항해하는 동일 계열 선박, 미국 국기와 긴 보닛 트럭·저층 산업지로 장소를 구별한다. 카메라는 중국 육지→바다, 선미→선수, 미국 바다→내륙, 입고 도크→랙→포장→출고 도로를 보여 준다. 작은 도색 인물, 모형 받침 단면과 매크로 심도로 축척감을 강화했다.

현재 한국어·중국어 검토 페이지는 V2이며, 아래 기존 V1 기록과 자산은 보존했다. 최신 자산·좌표는 [V2 manifest](../../continuity-v2/manifest.json), 변경 근거·프롬프트·재현 방법은 [V2 제작 기록](../../continuity-v2/README.md), 실제 UI 검사는 QA 캡처는 배포 패키지에서 정리했으며, 필요 시 `continuity-v2/qa.cjs`로 재생성한다를 따른다. 국가 단서는 가상 세트이며 특정 실제 시설이나 노선을 주장하지 않는다. 대표 해상 여정을 시각화했고 항공 서비스 대안 자체를 변경한 것은 아니다. 실제 영상이나 연속된 3D 카메라 이동은 후속 파일럿 검증 범위다.

## 참고 자산과 미술 문법

REF-STYLE-01은 공간·재질·깊이·브랜드 표면의 강조 방식만 참고했다. 흰색과 라이트그레이 콘크리트, 네이비 구조물, 금속·골판지·필름·고무의 재질 차이를 적용한다. 원본의 녹색·사선 두 줄 심벌·다른 워드마크·특정 시설/지리 구도는 배제한다. 원본 픽셀을 새 이미지에 복사하거나 공개 산출물에 재배포하지 않았다.

REF-LOGO-01은 사용자가 지정한 유일한 원본이다. 1500×400 RGBA WebP와 알파·해시를 확인했다. 검게 보이던 부분은 투명 영역이다. 투명 여백만 [49,113,1450,287]로 잘라 원본 비례의 1401×174 PNG를 만들었다. 원본은 변경하지 않았다. 빈 중립 패널을 생성한 뒤 이 원본을 표면 투시로 후합성한다. 각 실제 좌표와 inverse homography는 [logo-placements.json](../../data/logo-placements.json)에 보존한다. 로고를 AI나 폰트로 다시 그리지 않는다.

정밀 산업 미니어처의 축척 목표 1:87–1:100은 연출 지침이며 실측값이 아니다. 약간 높은 3/4 medium-wide, 작은 PPE 작업자, 중간 심도, 일정한 낮 외부광을 기준으로 했다. 실제 생성은 일부 장면에서 실물 사진 같은 카메라·축척감이 남았으므로 이를 충족한 것으로 과장하지 않는다. S01은 높은 시점으로 한 차례 재생성했고, 알파가 있는 수정안은 기록된 중립 배경에 합성해 불투명 정지 이미지로 내보냈다. S05 모바일은 작업자가 지나치게 커 보여 한 차례 수정안을 생성했다. 최종 선택·한계는 검증 기록을 따른다.

브랜드 원색은 #00ABE1이고 UI CTA·포커스는 기존 #007FA8 토큰이다. 성공 상태 녹색은 수정하지 않았다. 실제 시설·선단·항공기·창고 규모·처리량·통관 성과의 증거로 이미지를 설명하지 않는다. 검토 UI에는 `概念示意`와 임시 카피 상태를 표시한다.

## 정지 프레임 animatic

독립 HTML 보드에서 30초 가상 시간/정규화 진행을 range 입력으로 앞뒤 탐색한다. 각 장면은 5초의 검토용 구간이며 5개 경계에 컨테이너 면을 연상하는 불투명 전경 마스크가 들어왔다가 다음 장면에서 나간다. 단순 crossfade가 아니다. 합성된 이미지 전체가 함께 미세 이동하므로 로고가 별도 화면 스티커처럼 남지 않는다. 텍스트 진입·유지·퇴장은 timeline 데이터에 기록한다.

휠·터치를 가로채지 않는다. 기본 방향키·Home·End 입력을 보존하며 모든 장면을 위쪽의 일반 정적 콘텐츠로도 볼 수 있다. 모션 감소에서는 이미지 이동·줌·가림 애니메이션과 텍스트 페이드를 없앤다. 이미지 오류는 읽을 수 있는 안내와 해당 단계 설명을 표시한다. 실제 영상·3D 연속성·시간적 로고 안정성·초기 로딩/시킹 성능은 이 보드로 검증한 것이 아니다.

## 도구와 실행 한계

creative-production:produce의 시각 제작·원본 보존·정확한 콘텐츠 지침과 imagegen을 적용했다. 다중 정지 생성은 해당 스킬의 지침에 따라 생성 담당 에이전트로 분리했다. Creative Production 보드 도구는 직접 호출할 수 없고 functions.exec 경유는 스킬에서 금지하므로, 사용자 요청의 독립 로컬 검토 페이지로 전달한다.

일반 exec, view_image, node_repl은 Windows sandbox helper 초기화 오류가 발생했다. 승인된 개별 exec 명령으로 파일 작업을 실행하고 이미지 바이트를 읽기 전용으로 표시해 원본과 결과를 직접 검토했다. Playwright-interactive 스킬을 읽었으나 persistent node_repl은 같은 오류로 실행되지 않았다. 기존 설치 Playwright와 Chrome의 스크립트 검사로 대체했고 새 의존성을 설치하지 않았다. 추론 모델은 GPT-6 계열이며 정확한 런타임 ID가 노출되지 않아 임의 모델 ID를 기록하지 않았다. 이미지 도구는 built-in image_gen.imagegen이다. 모델 ID·seed·비용 미노출은 각각 unknown/not_available로 남긴다. 별도 유료 API나 영상 생성 도구를 호출하지 않았다.

#24에는 S01+S02 가로/세로 키프레임·base·원본 로고 경로/해시·투시 합성정보·마스크·프롬프트·연결 의도와 [파일럿 판정표](../../qa/pilot-checklist.md)를 전달한다. #62는 파일럿 측정 후 실제 해상도·fps·코덱·대역폭·시킹·preload·fallback·manifest를 확정한다. #42 홈 구현은 선행하지 않는다.

## 비교의 한계

A/B/C는 각각 독립 생성한 이미지이므로 동일한 3D 장면의 조명 또는 카메라만 엄밀히 교체한 실험은 아니다. B에서 조명 이외의 카메라 높이·배치 차이도 남는다. 방향 비교 자료로 제출하며, 통제된 동일 지오메트리 비교를 완료했다고 주장하지 않는다.

## 최종 수정안 선택

S01·S03·S04 모바일과 S03·S04·S05 데스크톱은 높은 카메라와 작은 작업자 비례가 개선된 v2를 선택했다. S06 데스크톱은 비공식 엠블럼이 제거된 v2를 사용한다. S01 데스크톱도 높은 시점의 v2를 중립 배경에 합성했다. S05 모바일 v2는 테이블/작업자 접점이 모호해 기각하고 기존 v1을 유지했다. 총 생성 수에는 이러한 미선택 시안도 포함하며, 정확한 수량과 해시·관계는 assets.json을 따른다.
