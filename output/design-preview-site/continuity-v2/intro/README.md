# 기본 버전 · 로고 인트로

공식 `resources/logo/PNP-LINE.webp`의 알파 채널을 그대로 사용한다. 글자 내부에만 사용자가 첨부한 중국 항만 이미지가 보이고, 바깥은 페이지 배경색 `#f7f8f5`로 덮인다. 로고를 다시 그리거나 폰트로 대체하지 않는다.

- 0–0.6초: 화면 중앙에 로고를 유지한다.
- 0.6–3.8초: 항만 이미지를 고정한 채 로고 마스크를 96배까지 확대한다. L의 불투명 획을 확대 중심으로 삼아 마지막에는 화면 전체가 열린다.
- 3.8–4.0초: 첨부한 항만 전체 화면을 보여 준다. 모바일은 화면 비율에 맞춰 중앙을 보여 준다.
- 4.0–4.5초: 기존 첫 키프레임으로 부드럽게 이어진다. 모바일은 기존 세로 키프레임으로 연결된다.
- 4.5–34.5초: 기존 여섯 장면을 각 5초씩 재생한다.

세 정적 키프레임(0.0 / 1.9 / 3.9초)은 기본 버전의 여정 앞에 표시하며, 클릭하면 애니매틱의 해당 순간으로 이동한다. 재생·정지, 슬라이더 탐색, 버전 변경 시 재생 중지를 지원한다. 동작 줄이기 설정에서는 로고를 고정하고 자동 재생을 비활성화하며 장면 버튼으로 건너뛸 수 있다.

`china-harbor.png`는 첨부 파일 `codex-clipboard-515f3942-0ffe-4fe0-b5cb-99187b83fc03.png`의 원본 복사본이다. `intro.js`가 SVG 마스크와 키프레임을 구성하고 `../review.js`가 타임라인을 제어한다. 고유 SVG ID를 사용해 정적 키프레임과 재생 화면 사이의 마스크 충돌을 방지한다.

검증: `node output/design-preview-site/continuity-v2/intro/qa.cjs`. 결과는 `qa-results.json`, 데스크톱·모바일 캡처는 이 디렉터리에 저장한다.
