# V2 · 중국 출발에서 미국 출고까지

2026-09-14 사용자 피드백 반영. 검토 대상은 실제 영상이 아닌 12개 정지 키프레임과 카메라 러프다.

## 변경 기준

| 요구 | V1의 문제 | V2 반영 |
| --- | --- | --- |
| 중국과 미국 구별 | 익명 창고·항만이 반복됨 | 중국 국기와 밀집 해안 배후 도시 / 미국 국기, 긴 보닛 트럭, 저층 산업지와 도로 |
| 카메라가 여정을 암시 | 매번 오른쪽 시설을 같은 높이에서 바라봄 | 중국 육지→바다, 선미→선수, 미국 바다→내륙, 도크→랙→포장→출고 도로 |
| 미니어처 비주얼 | 대형 건축 렌더에 가까움 | 작은 도색 인물, 모형 받침 단면, 섬세한 구조물, 모형 수면, 매크로 심도 |

데스크톱은 오른쪽으로 진행하는 화물의 시선을 기준으로 제작했다. S04에서 트럭은 도크에 후진 접안하므로 차량 방향보다 도크에서 안으로 이동하는 화물이 연결 기준이다. 모바일은 별도 세로 구도를 생성했으며 데스크톱 이미지를 잘라 사용하지 않았다.

파란 컨테이너, 검은 코너 피팅, 밝은 로고 패널, 파란 띠의 크라프트 화물이 반복되는 연결 단서다. S03–S06은 흰 외벽과 남색 기둥, 세 개의 도크, 노란 볼라드로 같은 미국 창고를 이어 가도록 참조했다. 생성 이미지이므로 모든 기하가 같은 3D 모델처럼 정확하게 일치한다고 주장하지 않는다.

국기와 건축·차량 단서는 국가를 보여 주기 위한 가상 세트다. 특정 항만·도시·실제 시설이나 자산 소유의 재현이 아니다. 국제 운송 프레임은 공간 이동을 분명히 보여 주는 대표 해상 여정에 집중했다. 이것이 실제 서비스의 항공 대안을 없애거나 해상 운송만 제공한다는 뜻은 아니다.

## 검토 화면

현재 최신 검토 경로는 `../index.html#a-site`에서 시안 A를 선택한 뒤 키프레임 보기를 여는 방식이다. 키프레임 데모는 `../keyframes.html#animatic`으로 직접 열 수 있다. 이전 V1 HTML은 정리했으며 현재 패키지에는 최신 검토 화면만 남긴다.

- 넓은 왼쪽 문구 공백을 없애고 장면이 가로 화면을 채운다.
- 문구는 이미지 밖에 놓고 전체 장면을 가리지 않는다.
- 중국 / 태평양 / 미국 경로와 현재 카메라 방향이 계속 보인다.
- 반복되는 가림 벽을 제거하고 장면의 실제 관계를 검토할 수 있는 직접 컷을 사용한다.
- 30초 러프 재생, 일시 정지, 슬라이더, 장면 버튼을 제공한다.
- 동작 줄이기 설정에서는 재생·이동을 멈추고 정적 장면을 제공한다.
- JSON fetch 없이 data.js를 읽으므로 file://에서도 동작한다.

실제 생성 영상, 중간 이동 프레임, 정확한 3D 카메라 연속성은 만들거나 검증하지 않았다. 다음 파일럿에서 S01→S02, S02→S03의 동일 화물·스크린 방향·브랜드 안정성을 검증해야 한다.

## 파일

- base/: 새로운 생성 원본. 기존 V1 자산은 그대로 유지한다.
- receipts/: 실제 생성 프롬프트, 입력 전달 방식, 반환 경로, 로고 좌표, 시각 검토.
- keyframes/: 공식 투명 로고를 원근 합성한 검토 이미지.

- `manifest.json`, `data.js`: 최신 12개 키프레임의 경로·해시·국가·카메라·구도.
- `intro/`: 로고 인트로에 사용하는 최신 보조 이미지와 기록.
- QA 캡처·결과 파일은 배포/검토 패키지에서 정리했으며, 재검증 시 `qa.cjs`가 다시 생성한다.

이미지 생성 모델의 정확한 ID·비용은 도구에 노출되지 않은 경우 추정하지 않는다. 실패한 파일 참조 읽기와 실제 이미지 생성 시도는 영수증에서 구분한다.

## 재현

저장소 루트에서 다음 순서로 실행한다. 생성 원본과 최신 키프레임을 다시 만든 뒤 통합 리뷰 화면에서 결과를 확인한다.

~~~powershell
python output/design-preview-site/continuity-v2/build.py
python output/design-preview-site/continuity-v2/install.py
node output/design-preview-site/continuity-v2/qa.cjs
~~~
