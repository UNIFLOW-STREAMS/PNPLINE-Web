## 모바일 세로 원본 적용 (revision=3)
- 모바일은 10–15초 미국 항만 도착, 15–20초 입고, 20–25초 포장, 25–30초 배송 순서로 사용자 첨부 세로 PNG 네 장을 사용합니다.
- us-arrival-mobile.png, us-receiving-mobile.png, us-packing-mobile.png, us-dispatch-mobile.png는 첨부 원본을 수정 없이 복사한 파일입니다.
- 9:16 원본 구도를 유지하며 확대는 최대 1.025배입니다. 데스크톱용 좌우 이동은 적용하지 않습니다.
- 썸네일과 로고 보호 영역도 선택한 화면 비율에 맞게 전환합니다. 화면 비율을 바꿔도 재생 위치는 유지합니다.
- 데스크톱은 기존의 가로 원본과 15초 전환 시점을 유지합니다.

## 타임라인
- 0–5초: 중국 부두에서 선박으로 카메라가 이동하면서 확대율을 조정합니다.
- 5–10초: 태평양을 횡단하며 미국 항만으로 접근합니다.
- 10–15초: 미국 항만에서 창고 방향으로 확대합니다. 마지막 0.7초에 낮은 사선 입고 이미지로 디졸브합니다.
- 15–20초: 사용자 첨부 1, us-receiving.png. 컨테이너 하역 → 지게차 → 보관 랙.
- 20–25초: 사용자 첨부 2, us-packing.png. 포장 작업대 → 컨베이어 → 트럭.
- 25–30초: 사용자 첨부 3, us-dispatch.png. 출고 도어 → 배송 차량 → 미국 도로.

## 구현
- 검토 페이지: ../ko-c.html?revision=10#animatic
- 하이 앵글 카메라는 이동과 확대를 함께 보간합니다. 시작 가장자리에서도 확대율이 변하므로 카메라가 정지하지 않습니다.
- 미국 입고 이후에는 하이 앵글 세계와 경로 인디케이터를 숨기고 첨부 원본을 사용합니다.
- 세 첨부 PNG는 수정 없이 복사했습니다. 원본에 포함된 로고를 그대로 표시합니다.
- 미국 시퀀스는 이미지의 이동·확대와 0.7초 디졸브입니다. 실제 3D 카메라 하강이나 선박·작업자 동작 영상은 아닙니다.
- 모바일은 같은 첨부 이미지를 주요 작업과 배송 차량 중심으로 따라갑니다.
- 전체 지도는 별도 정지 검토 모드이며 재생 또는 슬라이더 조작 시 추적 모드로 복귀합니다.
- 모션 감소 설정에서는 자동 재생을 끄고 각 구간을 고정 구도로 표시합니다.
- 첫 전경은 내장 image_gen 도구로 생성했습니다. 원래 생성 프롬프트는 prompt.txt입니다.

# 로고 인트로

기본 버전과 동일한 4.5초 로고 마스크 인트로를 데스크톱과 모바일 타임라인 앞에 배치한다. `continuity-v2/intro.js`와 공식 `resources/logo/PNP-LINE.webp`를 공유하며, 하이앵글 첫 키프레임을 복사한 `high-angle-c/intro-harbor.png`를 글자 내부에 보여 준 뒤 같은 구도의 실시간 하이앵글 중국 부두 장면으로 디졸브한다. 전체 길이는 34.5초다.

- 0–4.5초: 로고 마스크 확대와 항만 전체 화면
- 4.5–34.5초: 기존 하이앵글·미국 창고 30초 여정
- 화면 비율 변경 시 현재 시간을 유지하고 해당 비율의 인트로로 교체
- 동작 줄이기에서는 확대를 멈추고 재생 버튼을 비활성화
- 인트로 썸네일과 세 검토 키프레임에서 해당 시점으로 이동 가능
