# 브랜드 원본과 표면 합성

공식 원본은 `REF-LOGO-01`, 저장소의 `docs/plan/issue-61-brand-miniature/references/PNP-LINE.webp`이다. SHA-256은 `051a5181409ba202f6cbfe7d967582016413d57cf9c2b1a9665eaffe1a2a843c`이다.

원본 캔버스는 1500×400이고, 알파가 존재하는 실제 글자 영역은 [49,113,1450,287]이다. 파생본은 투명 여백만 잘라 1401×174로 만든다. 글자의 획·자간·색을 바꾸지 않는다. 파생본을 폰트로 다시 그리거나 AI에 넘겨 로고 재생성을 요구하지 않는다.

## 재현 순서

1. 실제 생성된 base scene의 중립적인 빈 패널을 직접 확인한다.
2. `data/logo-placements.json`에서 확인한 표면 모서리와 실제 로고가 차지할 사각형을 기록한다. 좌표 원점은 좌상단이며, 정규화 좌표이다. 배열 순서는 좌상·우상·우하·좌하이다.
3. 투명 여백을 정리한 로고를 원본 비례로 준비하고, 단일 평면 homography로 표면에 투영한다. 일부 글자를 독립적으로 변형하지 않는다.
4. `scripts/composite.py`를 실행한다. 기존 Pillow/NumPy로 픽셀 레이어를 합성한다. 비균등 화면 리사이즈는 없으며, 검토용 16:9 / 9:16 캔버스에는 원본을 비례 유지해 맞추고 남는 최소 여백을 중립색으로 채운다.
5. 원본 대비 확대본과 최종 전체 프레임을 함께 확인한다. 결과가 원본과 다르면 파일 존재 검사를 통과하더라도 시각 판정은 실패다.

각 프레임에 주 표식 하나만 적용한다. 보조 표식은 추가하지 않았다. 이 개수는 본 제작의 선택이며 사용자 승인 수치가 아니다. 로고 영역 주변은 패널 안의 남는 여백으로 확보하며, 주 물류 동작과 UI 카피를 덮지 않는다. 가림이 필요한 위치를 피한 빈 패널을 선택했으므로 정지 합성에서 별도 전경 가림 마스크는 없다. actual placement 데이터에 `occlusion: none; unobstructed surface`를 명시한다. animatic에서는 로고가 포함된 이미지 전체가 함께 움직이며 불투명한 전경 마스크가 이미지를 덮는다.

원본 색을 보존하기 위해 별도 색조·반전·광택 필터는 적용하지 않는다. 이 선택으로 표면 조명과 로고의 미세한 질감 반응은 제한적이며, 특히 B의 저녁 조명에서는 패널에 부착한 표식처럼 보이는지 사람의 검토가 필요하다. 정확한 영상 표면 추적·시간적 안정성은 #24에서 검증한다.

정지 이미지 생성 모델에는 로고를 전달하지 않는다. 개별 `execution-*.json`에 실제 이미지 참조 사용 여부를 기록한다. 로고 원본은 후합성에만 사용한다. 외부 공개·재배포 권한은 별도 확인 대상이다.
