01 / APP

Next.js + TypeScript

32개 라우트의 정적 생성, 메타데이터, scroll-world, 견적 폼을 하나의 프로젝트에서 관리합니다.

02 / CONTENT

JSON + Markdown

주소·요율·운영 수치는 JSON을 단일 기준으로 사용하고, 페이지 카피와 SEO는 Markdown 또는 코드로 버전 관리합니다.

03 / HOSTING

Aliyun 중심 배포

정적 사이트, CDN, DNS, SSL과 www에서 대표 도메인으로의 301 리디렉션을 구성합니다.

04 / FORM

서버리스 API + 관리형 DB

중국 내 리전을 우선 검토하고, 입력 검증·동의 확인·허니팟·IP 및 이메일별 요청 제한을 적용합니다.

05 / SEARCH

자동 sitemap · robots

공개·canonical 상태인 경로만 자동 포함하고, 검수 중인 페이지와 임시 빌드는 noindex로 차단합니다.
