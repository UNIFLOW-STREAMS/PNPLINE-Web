# PNPLINE 몰입형 V2 검토본

설치 없이 동작하는 독립 정적 HTML/CSS/JavaScript 시안입니다. 기존 비교본은 변경하지 않았습니다. 범위는 히어로·서비스·견적이며, 실제 운영 게시본이 아닙니다.

## 실행

```powershell
python F:/pnpline-landing/output/landing-immersive-v2/server.py
```

출력된 로컬 URL을 엽니다. 고정 포트가 필요하면 `--port 8768`을 추가합니다. 서버는 `127.0.0.1`에만 바인딩하고 이 폴더의 공개 정적 파일만 제공합니다. MP4 byte range를 지원합니다. 폴더 목록·상위 폴더·개발 문서는 제공하지 않습니다.

## 구성과 검토

- `index.html`: 확정 중문 V4의 세 영역, 동일한 여섯 견적 항목 및 동의.
- `style.css`: 밝은 정보 면과 정규 굵기 중문 타이포그래피, 전체 화면 영상, 모바일 전용 하단 정보 구성.
- `script.js`: 원본 33초 영상의 정방향·역방향 스크롤 seeking, 탭 키보드 조작, 비전송 견적 상태.
- `privacy/index.html`: 운영 개인정보 전문을 대신하지 않는 별도 경로 검토용 안내.
- `assets/warehouse-miniature.png`: 서비스의 주요 미디어로 사용한 창고 3D 단면 이미지. 실제 시설 사진이 아닙니다.
- `assets/provenance.json` 및 래스터 sidecar: 로고·폰트·영상·스틸·생성 이미지의 원본 및 처리 이력.

영상 시점은 0부터 `duration - 0.001`까지 스크롤 진행률에 선형 대응합니다. 자동 재생하지 않으며 정지 시 현재 프레임을 유지합니다. 모션 감소·미디어 실패 시 대표 이미지와 일반 스크롤로 바뀝니다. 상단 견적 링크는 영상 중간에서도 즉시 접근할 수 있습니다.

창고의 네 업무는 네이티브 disclosure이며, 나머지 세 서비스는 키보드 화살표·Home·End를 지원하는 탭입니다. 모든 서비스 문구는 DOM에 보존됩니다. 견적 입력은 외부로 보내지 않습니다. 제출 후 “设计预览：信息未发送。”만 표시하며, 입력한 이메일 형식이 잘못되면 원고의 오류 문구를 표시합니다. 필수 항목 정책은 임의로 확정하지 않았습니다.

미디어는 상징적 작업 영상·미니어처이며 실제 시설 증빙이 아닙니다. 원본 영상 선정, 중국어·서비스 사실·필수 항목·개인정보 전문·실제 접수 연결은 운영 검토 대상으로 남아 있습니다.

## 반영 범위와 검증 상태

중문 V4는 총 8개 영역이며, 이번 디자인 검토본에는 히어로·서비스·견적 3개 영역만 구현했습니다. 고객 유형, 창고·시스템 운영 설명, 진행 절차, 비용 안내, FAQ 5개 영역은 원고에 남아 있으며 이 화면에는 아직 구현하지 않았습니다. 개인정보 경로도 정식 정책 대신 검토용 안내입니다. 전체 MVP 완성본으로 해석하지 않습니다.

주 구현은 GPT-6 Astra, reasoning effort ultra 담당이 수행했습니다. 실제 브라우저에서 1440×900·390×844·320×568·사용자 1280×720, 정방향/역방향 영상 시점과 정지 유지, 앵커, 서비스 키보드 조작, 이메일 오류·비전송 상태·개인정보 경로를 확인했습니다. 모션 감소와 미디어 실패는 소스 경로 확인까지이며 실제 설정·요청 실패 시험은 하지 않았습니다.

독립 finish review는 서비스 탭의 펼침 오인 표시 1건을 지적했고, 아래 화살표를 제거한 데스크톱·모바일 재캡처에서 해당 수정이 resolved, 최종 disposition `ship`으로 판정됐습니다. 이 판정은 해당 수정 검토의 범위이며 운영 공개나 사용자 디자인 승인을 뜻하지 않습니다. 상세 근거는 프로젝트 `.impeccable/review/immersive-v2/{qa.md,finish-review.md,final-verdict.md}`에 있습니다.

생성 창고 이미지는 네이티브 image generation의 신규 생성 모드로 제작했습니다. 정확한 프롬프트는 `assets/warehouse-miniature.prompt.txt`와 PNG 내부에 보존했고, 기존 WebP 출처는 origin sidecar에 기록했습니다. 최종 provenance scan은 7개 래스터 모두 통과했습니다.
