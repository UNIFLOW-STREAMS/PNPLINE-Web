# PNPLINE 미니어처 홈 컨셉 V1

기본 버전 히어로의 미니어처 비주얼을 확장한 간체 중국어 홈 시안입니다. 섹션별 독립 가로 시안 10장을 생성하고, 최종 검토 화면은 공식 로고와 실제 텍스트를 사용해 다시 조판했습니다.

## 보기
- index.html: 페이지 전체를 연속해서 검토합니다.
- 상단에서 화면 맞춤 / 1920px 원본 / 1440px 가이드를 전환할 수 있습니다.
- overview.jpg: 10개 섹션의 빠른 비교용 축소본입니다.
- 파일명이 -1920.png로 끝나는 10장이 최종 섹션 이미지입니다.
- studies/: 내장 image_gen으로 각각 생성한 초기 섹션 디자인 이미지입니다. 최종 픽셀 규격은 -1920.png를 기준으로 확인합니다.

## 규격
모든 최종 프레임의 폭은 1920px, 콘텐츠 영역은 1440px, 좌우 여백은 각각 240px입니다. 배경은 전체 폭을 사용합니다. 높이는 내용에 따라 다릅니다.

## 디자인
- 기본 애니메이션의 낮은 사선 카메라, 작은 인물·차량, 골판지·도장 금속·콘크리트 재질을 이어받았습니다.
- 브랜드 청록 #00ABE1, 버튼 #007FA8, 남색 #122C3D, 따뜻한 백색을 공통으로 사용했습니다.
- 중국 출발 → 미국 직영창고 → 미국 배송이라는 여정을 공통 이야기로 사용합니다.
- 흐름은 연속 모형, 고객 선택은 세 갈래 경로, 서비스는 네 작업 장면, 비용은 다섯 구성 요소로 표현했습니다.
- 긴 설명은 제목·짧은 라벨·도식으로 축약했습니다. FAQ 8문항과 문의 기본 6항목은 유지합니다.
- 구성 요소: 서비스의 구획 그리드, 세로 구분선, 운영 정보 패널, 크롭한 미니어처 이미지.
- 향후 모션 방향: 히어로의 스크롤 진행과 장면 사이의 부드러운 전환. 이번 결과물은 정적 디자인입니다.
- 공식 로고 원본은 헤더·푸터에 그대로 사용했습니다. 모형 내부의 작은 브랜드 표기는 생성 이미지의 일부입니다.

## 입력과 제작
- 콘텐츠: docs/pnpline-china-source-content/pnpline-home-a-content-brief-v3.md
- 로고: resources/logo/PNP-LINE.webp
- 비주얼: output/scroll-world-concept-v1/continuity-v2/keyframes/S01-desktop.jpg 및 기본 버전 시네마틱 검토 이미지
- 적용 스킬: imagegen-frontend-web, imagegen
- 생성 도구: 내장 image_gen. 각 섹션을 개별 호출했습니다. API/CLI 생성은 사용하지 않았습니다.
- prompts.json: 공통·섹션별 프롬프트와 원본 생성 경로
- CSS에서 생성된 장면 부분을 프레이밍하고, 텍스트·로고·UI를 1440px 그리드에 배치했습니다. PNG는 Chrome에서 1:1 출력했습니다.
- validation.json: 10개 프레임의 실측 폭·여백, 이미지 로드와 검토 조작 검증 결과

시설 모형과 WMS 도식은 개념 시안입니다. 실제 시설·제품 증빙이나 서비스 수치를 만들지 않았습니다. 미국 직영창고 포지셔닝은 브리프를 유지했습니다. 20 CBM·월 500건은 견적 설명용 조건입니다. 통관은 브리프의 미게시 대체 블록을 사용했습니다.

문의 폼은 디자인 검토용이며 데이터를 전송하지 않습니다. 메뉴는 검토 편의를 위해 페이지 내부 섹션으로 연결되며, 실제 서비스 페이지 및 언어 전환 구현을 의미하지 않습니다.
