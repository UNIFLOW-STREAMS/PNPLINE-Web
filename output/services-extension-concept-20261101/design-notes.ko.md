# PNPLINE Services 확장 컨셉
작성일 2026-11-01

## 배치
기존 Services 4개 항목 다음에 상세 화면 01–04를 연속 배치하고 기존 Customer Types로 이어진다. 4장은 신규 공개 URL이 아니라 하나의 랜딩에 추가할 섹션별 검토 시안이다. 기존 사이트 소스는 수정하지 않았다. 현재 영문 사이트와 연속성을 위해 영문 문구를 사용했다.

## 원고와 대응
원문은 docs/pnpline-china-source-content/pnpline-landing-mvp-copy-v4.zh-CN.md의 Services 문단이다.
1. 중국 출고와 미국 국내 운송 — FCL / LCL / 항공을 선택지로 비교. 화물량·크기·중량·출발지·도착지·시기·수리조건·인계범위 확인.
2. 창고와 주문 이행 — 단건 출고와 FBA 중계/보충을 두 경로로 구분. FBA 임시 보관, 라벨링, 분할 출고. 반품 검품·재라벨링·재입고, B2B 포장·라벨·예약 조건.
3. IOR와 수입 통관 상담 — IOR 요구, 신고서류, 상품·거래 정보, 당사자별 책임. HS 분류 및 FDA/FCC 관련 적용 요구와 지원 범위 확인.
4. 재고와 시스템 접속 — 재고조회·입고기록·주문/출고 진행, 판매 플랫폼·ERP·API 요구. 실제 기능·권한·갱신 방식·지원 범위 확인.

## 구성 도구
01 — 공유 행 기준 비교표. 운송수단별 속도·가격 순위를 임의로 매기지 않는다.
02 — 두 갈래 경로 + 비대칭 bento. 단건 주문은 구매자, FBA는 Amazon 창고로 향하는 차이를 먼저 읽는다.
03 — 서류 보드 + 상담 순서. IOR를 먼저 확인하고 HS/FDA/FCC 질문을 이어간다.
04 — 요구사항 관계도 + 확인사항 밴드. 점선은 연동 상담 요구를 뜻한다.

## 공통 제작 수치
1920px 기준, 본문 max-width 1320px / 양측 300px, H2 44–56px, 본문 18–20px, 버튼 높이 48–52px, 아이콘 32–44px, 1px 구분선, 작은 직각 모서리. White / #F4F6F7 / #172126 / #00ABE1.
생성 PNG는 1672×941이며 비율·배치 검토용이다. 생성 이미지의 글자 크기나 여백을 실제 CSS 수치로 역산하지 않고 위 제작 수치를 적용한다.

## 아이콘 제작 기준
운송 — 전용 컨테이너, 혼재화물, 항공기, 체적, 저울, 핀, 시계.
작업 — 창고, 포장, 상자, 구매자, 라벨, 팔레트, 반품, 검품, 재입고.
수입 — 담당자+서류, 신고문서, 분류태그, 상품확인.
시스템 — 상점, ERP 레이어, API, 선반, 입고문서, 출고, 권한, 갱신.
실제 구현에서는 같은 24×24 viewBox와 1.5–2px 선 두께의 SVG를 쓴다. 이번 산출물의 아이콘은 PNG 안에 표현된 디자인이다.

## 최종 검수
02 하단은 반품 경로(Inspect → Relabel → Restock)와 별도 B2B 체크리스트(Packaging / Labels / Appointments)로 구분했다. Amazon은 목적지 텍스트로 표시하고 아이콘은 일반 창고를 사용한다.
기능·서비스는 실제 지원범위 확인을 전제로 한다. 미니어처는 설명용 이미지다.

## 반응형과 상호작용 제안
01 — 데스크톱 비교표, 모바일은 운송수단 선택 탭과 같은 확인항목. 선택 시 아이콘/밑줄을 180ms 전환.
02 — 데스크톱 두 경로, 모바일은 단건/FBA 탭과 하단 반품·B2B 독립 블록. 선택 경로의 선을 280ms에 걸쳐 강조.
03 — 모바일에서 IOR → 서류/HS/FDA·FCC → 상담 순서로 적층. 질문 선택 시 설명을 240ms 펼침. 일반 설명은 항상 표시.
04 — 모바일은 플랫폼/ERP/API 요구 → 창고 → 기록 항목을 세로로 재배치. 항목 선택 시 해당 연결선만 300ms 강조.
prefers-reduced-motion에서는 이동 애니메이션 없이 선택 상태를 즉시 표시한다.
모든 CTA의 실제 구현 목적지는 기존 #quote다.
