# 중문 V4 콘텐츠 보존 검토

검토일: 2026-11-01
원문: `docs/pnpline-china-source-content/pnpline-landing-mvp-copy-v4.zh-CN.md`

- 히어로·서비스·고객 유형·창고/시스템·진행 절차·비용·FAQ·견적의 8영역과 기존 앵커를 보존했다.
- 히어로 H1, 브랜드 문장, 첫 보조 문단을 보존했다. 두 번째 보조 문단은 합의된 계획에 따라 서비스 도입부로 이동했다.
- 서비스 4개 이름·본문과 창고의 작업 4개를 모두 보존했다. IOR·HS·FDA·FCC의 자료·책임·지원 범위 확인 문구를 유지했다.
- 고객 유형 3개와 각 작업·납품 조건을 보존했다. 플랫폼명이 공식 협력·인증을 의미하지 않는다는 안내를 유지했다.
- 직영 운영, 화물 인계, 재고·권한·갱신·연동 범위의 본문을 보존했다.
- 상담 3단계, 비용 5개 항목·조건, 최소 과금·장기 보관·특수 작업·추가 비용 안내를 보존했다.
- FAQ 8개 질문과 답변을 축약 없이 보존했다.
- 폼 6개 필드와 V4의 모든 선택지를 보존했다. 필드 순서는 동일하다. 미정·불명 선택지를 기본값으로 두었다.
- 동의 문구, 개인정보 독립 경로, 제출 라벨·견적 조건 문구를 보존했다.
- 고객 유형과 창고 영역의 반복 견적 버튼만 섹션 계획에 따라 생략했다. 공통 헤더·히어로·서비스·비용·푸터의 견적 경로는 유지했다.
- 서비스/창고 증빙용 실제 이미지를 발명하지 않았다. 지정된 네 IMAGE placeholder 자산 경로만 참조하며 alt도 실제 사진이 아닌 자리표시자임을 명시한다.
- 개인정보 페이지는 기존 검토용 안내의 취지를 유지하며 법률 전문을 발명하지 않았다. 폼은 method=dialog, 제출 버튼은 type=button으로 설정해 JS 없이도 네트워크로 정보를 보내지 않는다.
- 삭제된 스크롤 안내 문구·콘셉트 표식·S1~S7 해설·자동재생은 추가하지 않았다.

새 UI 안내: 메뉴 접근성 라벨, 미리보기 비전송 문구, 필드 오류 문구, 관련 서비스로 이동하는 링크. 실제 서비스 약속은 추가하지 않았다.

본 문서는 콘텐츠 검토 기록이다. 브라우저 동작·반응형 검증은 부모 작업의 QA 기록을 따른다.

정적 HTML 검증 결과: 본문 8영역, FAQ 8개, 중복 ID 0개, 잘못된 페이지 내 앵커 0개. V4의 독립 본문 문단을 HTML 텍스트와 대조했으며 누락 0개였다. 히어로 video는 src 없이 data-src만 가지며 preload=none, muted, playsinline이고 autoplay·loop는 없다. footer의 실제 모션 감소 설정 체크박스와 개인정보 새 창 안내 접근성 라벨을 추가했다.
