## 검증 중 반영한 수정

- sticky 헤더 높이를 포함해 영상 진행도를 계산하여 시작점과 마지막 프레임의 오프셋을 바로잡았다.
- 높이 540px 이하 또는 히어로 문구가 가용 높이를 넘으면 긴 영상 고정을 해제한다. 크기·글꼴 변화도 다시 측정한다.
- 내부 이동에 중복 적용되던 여백을 정리했다.
- 낮은 화면의 모바일 메뉴에 최대 높이와 내부 스크롤을 적용했다.
- 포스터를 기존 작업 영상의 0초 프레임으로 추출해 최초 영상 프레임과 맞췄다.

## 증거와 검증 범위

- 수치 기록: `review/browser-evidence.json`.
- 화면: `review/desktop-hero.jpg`, `desktop-services.jpg`, `desktop-evidence.jpg`, `desktop-process.jpg`, `desktop-pricing.jpg`, `desktop-quote.jpg`, `mobile-hero.jpg`, `mobile-services.jpg`, `mobile-faq.jpg`, `mobile-quote.jpg`, `mobile-320.jpg`, `mobile-reduced.jpg`, `mobile-landscape-menu.jpg`.
- 실제 브라우저 설정은 어두운 테마였다. 밝은 테마 토큰과 대응 규칙은 코드 검토했으며, 밝은 테마 화면 검증은 수행하지 않았다.
- 모션 감소는 실제 페이지 토글로 검증했다. OS의 `prefers-reduced-motion` 감지·변경 리스너·CSS 처리는 구현 및 코드 검토했으나 OS 설정 전환 자체는 브라우저 실증 범위에 포함하지 않는다. OS 설정은 변경하지 않았다.
- 모바일 크기 검증은 데스크톱 브라우저의 viewport 조절이다. 실제 iOS/Android 기기, 네트워크 지연·영상 실패·JavaScript 차단 상황에 대한 별도 기기 검증은 수행하지 않았다.

## 출시 전 남는 연결

현재 결과는 전체 랜딩의 로컬 구현이다. 견적 폼은 전송하지 않으며 개인정보 페이지는 정식 정책이 아닌 검토 안내다. 실제 접수 API, 접수 성공·실패 흐름, 확정된 개인정보 문안, 검증된 운영 자료, 최종 영상이 연결되어야 공개 운영할 수 있다. 검색 색인도 미리보기용 `noindex` 상태다.

AI 이미지·영상 생성 호출은 0건, 새 유료 생성 비용은 $0이다. 로컬 SVG 자리표시자 4개와 기존 영상 프레임 추출만 사용했다.
