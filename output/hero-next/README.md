# PNPLINE Hero — Next.js + Tailwind

Run npm install, then npm run dev. Open http://127.0.0.1:3088/.

The desktop and mobile artwork are the user's supplied PNG files, unmodified. All headings, CTAs, stages and captions are real accessible HTML. At 1920px the inner container is1440px with240px on each side; the artwork spans the full1920px. Below768px the picture element switches to the portrait artwork. The hero is isolated from earlier landing previews.

Get a Quote opens an inquiry draft dialog; its submit downloads a local text draft and does not transmit data. Explore Services opens a service overview. Stage buttons select an illustrative stage and do not claim shipment tracking or change the supplied still image. Dialogs support Escape and native focus trapping.

npm run build, npm run typecheck. No deployment configuration was changed.
