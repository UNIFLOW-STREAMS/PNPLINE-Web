# PNPLINE 몰입형 V3

중문 V4 원고의 **hero / services / quote 세 영역**을 재구성한 로컬 디자인 프리뷰다. `customers`, `evidence`, `process`, `pricing`, `faq`의 다섯 영역은 이번 작업 범위에 포함하지 않았다. 전체 MVP 구현이나 운영 게시 완료를 뜻하지 않는다.

## 실행

PowerShell에서:

```powershell
python F:/pnpline-landing/output/landing-immersive-v3/server.py --port 7330
```

브라우저에서 `http://127.0.0.1:7330/`을 연다. `server.py`는 V2의 로컬 HTTP Range 지원 서버를 그대로 복사했다. 외부 인터페이스에 노출하지 않고 `127.0.0.1`에서 이 폴더만 제공한다. 다른 포트가 필요하면 `--port` 값을 바꾼다.

## 이번 구성

- 상단 고정 내비게이션에 공식 로고, 서비스 링크, 작은 cyan 견적 행동을 둔다. 첫 화면의 흰 소개 영역은 제목과 설명·CTA를 두 열로 나누고 영상 위의 반투명 상자를 없앴다. 모바일은 제목·설명·행동 아래에 영상이 이어진다.
- sticky hero는 `100svh`이며 데스크톱 최소 높이는 650px이다. 초기 스크롤 진행률 `0–0.18`에서 소개가 위로 빠지고 영상 영역의 상단이 0으로 이동한다. 소개 높이는 실제 렌더 높이로 측정한다. 소개가 사라지면 `inert`로 숨은 링크의 포커스를 막고 역방향 이동에서 복원한다. 헤더의 견적 행동은 계속 접근할 수 있다.
- 네 서비스를 한 개의 이미지 tablist와 한 개의 공통 `tabpanel`로 통합했다. 네 원고 제목은 선택지에 한 번씩 표시하며 상세에서 다시 반복하지 않는다. 창고의 네 하위 작업은 모두 펼쳐진 2×2 설명이며 작은 모바일에서는 한 열이다.
- 로컬 Noto Sans SC 400 제목, 자간 `-0.008em`, 기본 본문 15–16px을 사용한다. 1280px 화면에서 hero 제목은 48px이며 서비스·견적 제목은 각각 더 작은 위계를 가진다.
- 견적 영역은 최대 1120px, 소개 300px와 폼 최대 680px로 구성한다. 필드는 52px 높이와 16px 입력 글자를 유지한다. 기본 필드 경계는 `#7b8b90`, 초점은 `#00799f`다. 제출 버튼은 내용에 맞는 폭이다.

## 원고와 동작 보존

기준 원고: `docs/pnpline-china-source-content/pnpline-landing-mvp-copy-v4.zh-CN.md`.

hero / services / quote의 제목·설명·창고 하위 작업을 포함한 19개 항목을 보존했다. `PNPLINE · 跨境物流服务` 서명은 제목 아래에 두었다. 새 성과 수치·주소·인증·운영 성능·마케팅 주장을 추가하지 않았다. 삭제된 스크롤 안내, `概念示意`, S1–S7 장면표는 넣지 않았다.

견적의 순서는 `产品类目 → 发货方式 → 月出货量 → 目的地 → 是否需要IOR服务 → 联系邮箱`이다. V2의 선택값·미정 기본값·설명·별도 동의 체크박스를 보존했다. 필수값과 동의 강제 등 운영 정책은 임의로 확정하지 않는다. 비어 있지 않은 잘못된 이메일은 인접 오류와 포커스로 안내한다.

**실제 문의를 전송하지 않는다.** `method="dialog"`와 submit `preventDefault()`를 유지하며 `设计预览：信息未发送。`를 표시한다. 이 상태는 제출 전에도 확인할 수 있다. `privacy/`는 독립 경로를 유지하지만 정식 개인정보 처리방침이 아니라 디자인 프리뷰 안내다.

서비스는 클릭과 키보드로 선택한다. 좌우 화살표는 순서대로, 2×2 모바일에서 상하 화살표는 같은 열로 이동한다. Home/End, 선택된 탭의 roving tabindex, `aria-selected`, 공통 패널의 `aria-labelledby`를 함께 갱신한다. 서비스·견적 앵커는 긴 영상 구간을 즉시 건너뛴다.

## 영상 검수 범위

**사용자의 최신 지시에 따라 영상 품질은 디자인 평가에서 제외한다.** 영상 파일, 프레임, 속도, 장면 순서와 품질을 수정하지 않았다. 이번 검수 대상은 영상 주변 UI의 읽기 배치와 스크롤 제어 동작이다. 이전 평가의 영상 품질 지적이나 이를 포함한 점수를 V3 판정으로 사용하지 않는다.

`assets/hero-scrub.mp4`와 `hero-poster.jpg`는 V2에서 바이트 단위로 동일하게 복사했다. 기존 33초 영상의 재생 시간은 `progress × (duration − 0.001)`로 선형 대응한다. 레이아웃 확장 진행률과 영상 시간은 별도이며 영상에 오프셋·가속·속도 변경을 넣지 않는다. 정방향/역방향 스크롤과 정지 시점 유지, paused 상태, autoplay/loop 없음은 유지한다.

모션 감소 또는 미디어 실패에서는 긴 sticky 구간과 펼침 연출을 해제하고 소개 뒤에 poster를 둔다. 320px 너비처럼 작은 화면은 최소 hero 높이 때문에 첫 viewport 아래로 콘텐츠가 이어질 수 있으며 고정 견적 링크를 유지한다.

## 자산 출처

- 공식 로고·로컬 폰트와 OFL·영상·poster·창고 미니어처는 V2에서 그대로 복사했다.
- `warehouse-miniature.png` 전체 형상은 창고, 같은 파일의 CSS 확대는 재고 선택지에 사용한다.
- `port-miniature.png`는 이번 V3용 imagegen 생성물이다. 선박과 항만 크레인을 CSS crop으로 나누어 운송·IOR 선택지에 사용한다. 부모 작업에서 준비한 PNG와 정확한 prompt를 그대로 보존했다.
- 두 생성 이미지는 개념적 미니어처이며 실제 PNPLINE 시설·선박의 증빙이 아니다. 영상에서 추출했던 기존 세 서비스 스틸은 이번 V3에 사용하거나 복사하지 않았다.
- `assets/provenance.json`, 기존 origin/JSON sidecar와 두 `*.prompt.txt`가 출처와 변환·SHA-256을 기록한다. 이미지 파일 자체는 편집하지 않았다.
