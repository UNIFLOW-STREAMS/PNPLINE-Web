# PNPLINE 중국어 사이트 콘텐츠 인벤토리

## 문서 목적

기준일: 2026-09-11  
근거 문서: `pnpline-cn-plan_1.docx` 2026-09-09 v1

이 문서는 `pnpline.cn` 중국어 사이트의 전체 콘텐츠 범위, 페이지별 필수 구성, 검수 항목을 정리합니다. 중국어 사이트는 한국어 사이트의 기존 26개 URL을 그대로 번역한 버전이 아닙니다. 중국 크로스보더 셀러가 바이두에서 서비스명을 검색하는 방식에 맞춰, 서비스와 검색 의도 단위로 새로 구성합니다.

기존 한국어 사이트의 26개 페이지는 서비스 정의, 실제 운영 정보, 기존 FAQ를 확인하는 원문 자산입니다. 중국어 사이트의 모든 페이지는 중국 셀러의 용어와 비교 기준으로 새로 집필하며, 기계 번역문을 재사용하지 않습니다.

## 확정된 방향

| 항목 | 결정 |
| --- | --- |
| 도메인 | `pnpline.cn` 독립 운영 |
| 주요 타깃 | 중국의 Amazon FBA/FBM 셀러, 독립몰 및 TikTok Shop 운영자 |
| 보조 타깃 | 미국 B2B 수출을 하는 공장·무역상, 중국 현지 포워더 파트너 |
| 전체 포지셔닝 | `韩资美国自营仓 · 合规 IOR 清关 · 韩美中三地一体运营` |
| 핵심 차별화 | Gardena(CA)·Katy(TX) 실제 직영 창고, IOR·Bond 기반 수입 통관, 자체 WMS와 API 연동 |
| 검색 엔진 | 바이두 우선 |
| 콘텐츠 원칙 | 서비스 페이지는 키워드 1개와 1:1로 연결하고, 중국어로 신규 집필 |
| URL | 한자 URL을 쓰지 않고 영문 슬러그를 사용 |

`双清包税`는 서비스명이나 광고 문구로 사용하지 않습니다. 검색 의도가 큰 표현이지만 저신고·회색 통관과 연결될 수 있어, 정책 해설 콘텐츠에서 컴플라이언스 관점으로 설명할 때만 다룹니다.

## 페이지별 추출·작성 체크리스트

모든 페이지에서 아래 항목을 한중 대조 콘텐츠 시트로 관리합니다.

1. 메타 타이틀, 메타 디스크립션, canonical URL, H1~H3, 섹션 카피, 표, FAQ, CTA, 내부 링크 앵커를 작성합니다.
2. 이미지마다 실제 내용을 설명하는 중국어 `alt`를 작성합니다. 창고 페이지의 이미지는 실제 시설 사진만 씁니다.
3. 폼 라벨, 도움말, 검증 오류, 성공·실패 메시지, 개인정보 동의, 쿠키 문구를 중국어로 작성합니다.
4. 요율, 리드타임, 처리 물량, 창고 주소·면적, IOR·Bond·FDA 관련 문구에는 사실 확인 담당자와 검수일을 표시합니다.
5. JSON-LD의 Organization, Service, FAQPage와 Open Graph 문구를 페이지 내용과 동일하게 맞춥니다.

## 출시 전 확인 사항

1. 중국 법인 명의의 ICP 备案, 도메인 실명 인증, `pnpline.cn` 등록자 명의가 일치하는지 확인합니다.
2. 중국어 상담 인력과 기업 WeChat의 운영 가능 여부를 확정합니다.
3. 공개할 요율의 범위를 확정합니다. 권장안은 구간 요율 공개와 최종 견적 병행입니다.
4. Gardena·Katy 외 실제 운영 거점과 주소를 확정하고, 세 국가 사이트 표기를 통일합니다.
5. IOR, 관세, De Minimis, T86, FDA·FCC 관련 문구는 공개 전 미국 통관팀이 기준일과 근거를 검수합니다.
6. Google Fonts, Google Analytics, Google Tag Manager, reCAPTCHA, YouTube, Facebook Pixel, 외부 jQuery CDN을 중국어 사이트에서 제거하거나 대체합니다.
