# PNPLINE 한 페이지 랜딩 통합 원고 V4 인계

작성일: 2026-10-31 (Asia/Shanghai)  
상태: 재작성 완료·내용/중국어/운영/개인정보 검수 대기. 승인된 공개 문안이 아니다.  
공개 범위: [2페이지 MVP](../mvp-single-page-scope.md). 이 문서는 `/` 원고이며 `/privacy/` 전문은 실제 처리 방침에 맞춰 별도 작성·검수한다.  
화면 원고: [간체 중국어 V4](pnpline-landing-mvp-copy-v4.zh-CN.md)

한국어 검토용 번역: [한국어 V4](pnpline-landing-mvp-copy-v4.ko.md). 중문과 같은 중국 출고·미국 물류 대상, 8개 섹션·앵커·서비스 조건을 유지했다. 별도의 한국어 사이트 경로를 공개하거나 서비스·개인정보 문구를 승인한 것은 아니다.

원고의 `#services`, `#quote` 등은 현재 랜딩 안의 섹션으로 이동하는 앵커다. 실제 사이트에서는 버튼이나 메뉴로 표현할 수 있다. `/privacy/`는 합의된 별도 개인정보 처리방침 페이지이며, 그 페이지에서 랜딩으로 돌아갈 때는 `/#quote`처럼 홈 경로를 포함한다. 원고는 구현된 사이트가 아니므로 Markdown 미리보기에서의 앵커 동작은 사용하는 뷰어에 따라 다를 수 있다.

## 기존 V3와의 차이

V3는 서비스·가격·시설·정책 상세 페이지로 분기하는 홈 원고였다. V4는 서비스 선택→신뢰 확인→이용 조건→비용→FAQ→한 개의 견적 폼으로 상담 결정을 한 페이지 안에서 마치도록 새로 작성했다. 원고를 이어 붙이거나 링크만 앵커로 바꾼 것이 아니다.

- 상세 페이지의 `了解…` 링크 대신 서비스의 대상·제공/제외 범위·견적 전 확인사항을 직접 설명한다.
- 주요 전환은 `获取物流报价` → `/#quote`다. 제출 동작은 `提交询价需求`다. 확인되지 않은 무료·즉시 회신·고정 배송일 약속은 넣지 않았다.
- 히어로는 스크롤 위치에 따라 영상의 특정 시점으로 이동하는 Scroll World다. S1–S7 장면 설명표·장면별 해설 캡션은 공개 원고에서 제외했다. 뒤의 process는 고객 상담·조건 확인 절차다.
- 뉴스·정책 해설 카드와 파트너·별도 언어 사이트 링크를 제외했다. 통관은 고객이 준비할 정보와 책임 확인에 필요한 내용만 남겼다.
- 실제 시설·자격·WMS 증빙은 별도 자료와 연결해 표시한다. 상징 영상을 실제 시설 사진처럼 설명하지 않는다.
- 20CBM·500주문 같은 견적 예시, 미확정 요율·성과 수치는 삭제했다. 비용 항목과 적용 조건을 비교할 수 있게 썼다.

## 문장 선택과 검토 대안

기본 H1은 `美国自营海外仓，衔接出货与订单履约`다. 확정된 미국 직영 운영을 먼저 말하고, 중국 출고부터 주문 이행까지 연결하는 범위를 설명한다. 모든 운송·통관·배송을 직접 수행하거나 무조건 책임진다는 의미로 확대하지 않는다.

대안 1: `美国自营仓，承接您的仓储与履约需求` — 창고 중심의 방문자에게 적합하다.  
대안 2: `从中国出货到美国履约，先明确您的物流方案` — 출발부터 도착까지의 상담 범위를 강조하지만 직영 차별성이 약해 기본안으로 택하지 않았다.

기본 CTA는 `获取物流报价`다. 대안은 `咨询物流方案`이며, 즉시 가격 제시보다 범위 상담을 우선할 때 사용할 수 있다. 최종 화면에서는 한 가지 주요 CTA로 통일한다.

## 히어로 Scroll World 동작 기준 — 2026-10-31 사용자 정정

방문자가 스크롤하면 해당 위치에 대응하는 영상의 특정 시점으로 이동한다. 스크롤 진행도 → 확정된 시간/프레임 매핑 → 해당 시점 표시가 기본 동작이다. 아래로 스크롤하면 뒤 시점으로, 위로 스크롤하면 앞 시점으로 이동하고, 스크롤을 멈추면 해당 시점을 유지한다. 시간 경과에 따라 영상을 끝까지 자동 재생하는 설명 영상 방식으로 구현하지 않는다.

- 공개 히어로의 문구는 브랜드 메시지·보조 설명·CTA다. 사용자가 삭제한 스크롤 안내 문구와 콘셉트 표식을 다시 넣지 않는다.
- S1–S7 이름·설명표·7개 해설 문단은 고객 화면의 본문이나 필수 캡션이 아니다. 별도 자막·내레이션·영상 플레이어를 기본 요구에 추가하지 않는다.
- 다음 표는 미디어 매핑 검토를 위한 내부 제작 정보다. 페이지에 노출하지 않는다. 구간별 실제 초·프레임은 선택된 작업본과 #62의 전달 명세를 따른다.
