상태: 검토용 콘텐츠 제안. 미국 창고의 직영 운영은 사용자 확인 사항으로 반영했다. 나머지 운영 정보, 중국어 원어민 검수와 법무·통관 검수가 완료된 공개 문안은 아니다.

## 0. 읽는 방법과 기준

이 문서는 사용자가 제공한 홈 A안에, 첨부 문서가 정의한 홈의 정보 영역을 보충한다. 32개 상세 페이지를 홈에 모두 복제하지 않는다. 한국어는 협업·검토용이고, `화면 문구`의 간체 중국어는 디자인 배치용 초안이다. `제작 주석`, `조건부 문구`, `확인 필요`는 고객 화면에 출력하지 않는다.

콘셉트는 **밝고 정돈된 서비스 선택형 B2B 랜딩**이다. 방문자가 제공 범위와 적합한 서비스를 이해하고, 운영 근거와 비용을 확인한 뒤 문의하도록 한다. 전환 중심이라는 이유로 신뢰 근거를 삭제하거나 모든 링크를 견적 버튼으로 바꾸지 않는다.

### 근거

- 사용자가 제공한 기존 홈 A안 원고.
- V3 수정 근거: 사용자가 이 대화에서 “미국 창고는 직영창고이다”라고 확인하고 반영을 지시했다. 직영 운영은 이 원고의 확정 입력이며, 외부 증빙 검토를 완료했다는 의미는 아니다.
- 첨부 `pnpline-cn-page-ia.md`: 공통 IA, 1. 首页, 관련 서비스·시스템·가격·문의 페이지. 문서 기준일 2026-09-13.
- 첨부 `pnpline-cn-plan_1.docx`: 2026-09-09 v1. 01 포지셔닝, 02 타깃, 04 핵심 페이지, 06 전환 동선, 07 FAQ, 09 언어 전환, 11 미결 사항.
- V2 작성 시 읽기 전용 레포 확인: `https://github.com/UNIFLOW-STREAMS/PNPLINE-Web`, `main`의 `89f99568d3216814d1b57334bf467a3fdca8ddca`.
- V2 작성 시 확인 파일: `CONTEXT.md`, `docs/pnpline-cn-page-ia.md`의 공통 규칙·홈 구간, `docs/wayfinder/design-system-v1.md`의 관련 규칙, `output/design-concept-v1/design-tokens.css`.
- V2 작성 시 확인 이슈: #63. 데스크톱 전체 페이지 PNG, 모바일 핵심 구간, 설명 문서가 디자인 검토 대상이다. HTML/CSS는 선택 가능한 이미지 제작 보조물이며 실제 API·폼 전송·영상 시킹은 범위 밖이다. 이슈의 최종 방향 승인 체크 항목은 조회 시 완료되지 않았다.
- V3는 로컬 콘텐츠 문서만 수정했으며 레포를 다시 조회하지 않았다. 이 문서 작성으로 레포 파일·이슈·승인 상태를 변경하지 않았다. taste 실행, 와이어프레임 이미지 제작, 사이트 구현도 수행하지 않았다.

### V3 확정 반영 — 미국 직영창고

- 확정 내용: PNPLINE은 미국 창고를 직접 운영한다.
- 한국어 핵심 표현: `미국 직영 해외창고`, `PNPLINE이 직접 운영하는 미국 창고`.
- 간체 중국어 핵심 표현: `美国自营海外仓`, `PNPLINE直接运营美国仓库`.
- 반영 범위: S1 히어로·보조 CTA, S2 물류 흐름, S4 단건 출고 설명, S5 창고 소개, S8-A FAQ, S8-B 목적지 선택, F0 브랜드 문구·시설 링크, 와이어프레임 지침과 상태 관리.
- 직영 표현은 기본 배치 원고에 사용한다. 사진·시설 수치가 아직 준비되지 않았다는 이유로 직영 자체를 다시 확인 대기 또는 조건부 문구로 되돌리지 않는다.
- 이 확인은 부동산 소유 여부, 모든 운송·통관·배송의 직접 수행, 한국계 자본·3국 운영, IOR/Bond 보유·자격, 면적·실적·가격·배송 기간을 추가로 확정하지 않는다.
- 주 메뉴의 `美国海外仓`는 IA의 서비스 분류명으로 유지한다. 모든 일반 명칭에 `自营`을 기계적으로 붙이지 않고 PNPLINE의 운영 방식을 설명하는 위치에서 명확히 사용한다.

### 콘텐츠 상태

- **기본 배치 원고**: 간체 중국어 초안. 서비스 제공 사실과 표현은 공개 전에 검수한다.
- **사용자 확인 완료·기본 반영**: PNPLINE 미국 창고의 직영 운영. 한국어 `미국 직영 해외창고`, 중국어 `美国自营海外仓`를 사용한다.
- **확인 후 추가**: 한국계·3국 운영, 실제 주소·시설 수치, IOR/Bond 보유 범위, 처리 실적, 요율, 정책 개정일, 상담 채널·회신 시간.
- **제작 주석만 허용**: 미확인 자산 요구, 출처, 승인 상태, 누락 데이터. 고객 화면에 `TBD`, 가짜 수치, 빈 증빙 카드를 넣지 않는다.

## S1. 히어로 — 제공 범위와 다음 행동

### 한국어 검토 원고

**미국 직영 해외창고와 주문 이행**

PNPLINE이 직접 운영하는 미국 창고를 기반으로, 중국 출고부터 창고 입고와 배송까지 필요한 물류 서비스를 연결합니다. 개별 주문 배송·FBA 중계 및 보충·국제운송·수입 통관 상담을 상품, 판매 채널, 물량에 맞춰 검토하세요.

주 행동은 무료 견적 받기, 보조 행동은 미국 직영창고 확인, 탐색용 텍스트 링크는 서비스 알아보기입니다.

### 화면 문구

- Eyebrow: `PNPLINE · 跨境物流服务`
- H1: `美国自营海外仓与订单履约`
- 보조 제목: `从中国出货，衔接美国自营仓与配送`
- 본문: `依托PNPLINE美国自营仓，围绕一件代发、FBA中转补货、头程运输与进口清关咨询，根据您的商品、销售渠道和货量，梳理适合的物流方案。`
- 주 CTA: `免费获取报价` → `/pricing/`
- 보조 CTA: `查看美国自营仓库` → `/about/facilities/`
- 텍스트 링크: `了解服务` → `#services`

### 확정 문구와 추가 확인 범위

H1의 `美国自营海外仓与订单履约`와 보조 CTA의 `查看美国自营仓库`는 사용자 확인을 반영한 기본 문구다. 더 이상 직영 확인 이후에만 적용하는 조건부 문구가 아니다.

기획서의 `韩资美国自营仓 · 合规 IOR 清关 · 韩美中三地一体运营` 중 미국 창고 직영은 확정되었다. ‘한국계’, ‘3국 일체 운영’, ‘자사 IOR 보유’와 실제 통관 서비스·책임 범위는 각각 별도로 확인한다. `一家公司全包`를 무조건적인 전 과정 책임 보장으로 확대하지 않으며, 직영을 부동산 소유 또는 모든 물류 단계의 직접 수행으로 표현하지 않는다.

### 제작 주석

히어로는 제목·제공 범위·CTA가 미디어와 무관하게 읽혀야 한다. 실제 시설 사진을 사용하면 출처·사용 권한을 확인한다. 상징적 Scroll World 정적 프레임을 쓰면 캡션 `概念示意`로 구분하고 실사진처럼 취급하지 않는다. 적합한 자산이 없으면 타입 중심의 온전한 레이아웃을 사용하고, 공백 사진 카드로 완성된 것처럼 꾸미지 않는다.

## S2. 전체 물류 흐름 — 중국 출고부터 미국 배송까지

### 한국어 검토 원고

**중국 출고부터 미국 배송까지, 전체 흐름을 확인하세요.**

중국 공장 → 국제운송 → 미국 통관 → 미국 직영 해외창고 → 미국 내 배송.

창고 입고·피킹만으로 전체 물류를 설명하지 않습니다. 화물 정보, 운송 방식, 통관 조건, 창고 작업, 최종 배송을 함께 확인하는 흐름입니다.

### 화면 문구

H2: `看清货物从中国到美国的每一步`

본문: `从出货资料到美国境内配送，先确认各阶段需要衔接的工作。`

| 단계 | 제목 | 한 줄 설명 |
| --- | --- | --- |
| 01 | 中国工厂 | 整理商品、包装与出货资料。 |
| 02 | 头程运输 | 根据货量与时效需求，评估整柜、拼箱或空运。 |
| 03 | 美国清关 | 核对申报资料、IOR需求与各方责任。 |
| 04 | 美国自营海外仓 | 衔接入库验收、库存管理与出库作业。 |

### 시각적 방향

현재 확인한 토큰을 사용한다. 공식 브랜드 원색은 `--brand-primary: #00ABE1`, 주 CTA는 `--action-primary: #007FA8`이다. 흰 배경·정돈된 정보 위계를 기본으로 하고, 과거 A안 설명의 녹색을 브랜드 주색으로 되돌리지 않는다. 이번 문서는 새 색상·타이포 시스템을 승인하지 않는다.

#63의 권장 검토 폭은 데스크톱 1440px이다. 실제 제작 폭·모바일 폭·배율은 제작자가 기록한다. 콘텐츠 최대 폭 등은 확인한 토큰을 따른다. 한국어 문장 길이로 화면을 맞춘 뒤 중국어를 마지막에 교체하지 말고, 위 중국어 초안으로 줄바꿈을 검토한다.

모든 섹션을 같은 카드 그리드로 반복할 필요는 없다. S2는 흐름, S3는 고객 분기, S4는 업무 비교, S5는 증빙, S7은 비용 구조라는 서로 다른 읽기 목적을 보존한다. taste는 레이아웃과 시각적 위계를 조정할 수 있으나, 필수 정보 삭제·수치 생성·서비스 약속 확대를 해서는 안 된다.

### 미디어 범위

실제 창고 사진, 자료 기반 재구성, 상징적 생성 자산을 구분한다. Scroll World를 사용할 때도 영상 속 시설·텍스트·숫자를 사실로 취급하지 않는다. 이번 콘텐츠 입력을 근거로 실시간 3D, Three.js, 6장면 전체 미디어, 유료 생성, 실제 영상 시킹을 자동 도입하지 않는다.

#63 시안은 데스크톱 전체 페이지 PNG와 모바일 핵심 프레임 및 설명 문서가 기준이다. 이 문서는 그 이미지 자체를 만든 결과물이 아니다. 이미지 출력이 필요하면 별도 승인 범위와 제작 도구를 확인한다.

## 부록 C. 콘텐츠 인수 기준

- AC-C1: H0, S1~S7, S8-A, S8-B, F0가 콘텐츠 명세에서 추적되고, 공개 불가 항목은 요구 삭제가 아니라 조건부·보류 상태로 구분된다.
- AC-C2: 고객 유형 3개와 핵심 서비스 4개가 서로 다른 질문에 답한다. Amazon FBA와 FBM의 역할을 섞지 않는다.
- AC-C3: FAQ 8개에 답변이 있고, 실제 표시할 답변과 관련 링크가 연결된다.
- AC-C4: 가짜 주소·시설 수치·가격·실적·자격·파트너·회신 시간이 없다. 처리 실적·구간 요율의 데이터 미확보가 완료로 표시되지 않는다.
- AC-C5: 중국어 화면 원고와 한국어 제작 주석이 분리된다. 사진·데모·개념 자산의 분류를 지킨다.
- AC-C6: 폼 구조·헤더·미디어·출발지·도메인 충돌을 실제 승인으로 해결하기 전, 본 콘텐츠를 최종 구현 명세로 선언하지 않는다.
- AC-C7: 와이어프레임은 선택한 폼 변형과 준비된 자산 상태를 명시하며, 두 폼을 합치거나 미확인 증빙으로 화면을 채우지 않는다.
- AC-C8: S1·S2·S4·S5·FAQ·문의 목적지·푸터의 한국어 및 중국어 문구에 미국 창고의 직영 운영이 일관되게 반영된다. 이를 확인 대기로 되돌리지 않으며, 부동산 소유·전 과정 직접 수행·자격·시설 수치의 확인으로 확대하지 않는다.
