## 1. 선택 결과

기존 작업 영상과 공식 로고·중문 폰트를 재사용한다. 서비스는 작업 설명과 같은 계열의 기능 아이콘으로 구성하고, 실제 시설처럼 보일 수 있는 기존 창고·항만 생성 삽화는 이번 기본안에서 제외한다. 실제 운영 증빙은 출처와 사용 범위가 확인된 자료만 사용한다. 자료가 없으면 해당 이미지 모듈을 생략하고 V4 설명을 유지한다.

현재 계획에 필요한 신규 유료 생성은 **0건, 신규 생성 이미지 0장, 예상 추가 생성 비용 $0**이다. 이번 작업에서 생성 도구를 호출하지 않았다. 과거 프로젝트 전체의 생성 비용·수량을 $0이라고 주장하지 않는다.

## 4. 서비스 설명용 시각 요소

서비스 삽화의 역할은 작업 종류를 구분하는 것이다. 창고의 실제 형태·규모·보유 설비·처리량을 보여주는 용도로 쓰지 않는다.

| 서비스 | 기본 시각 요소 | 설명이 맡을 내용 |
| --- | --- | --- |
| 仓储与订单履约 | 상자·포장에 해당하는 일반 선형 아이콘 1종 | 단건 출고, FBA 보충, 보관, 반품·B2B 작업의 차이 |
| 中国出货与美国境内运输 | 일반 운송 아이콘 1종 | FCL/LCL/항공과 미국 내 배송의 선택·인계 조건 |
| IOR与进口清关咨询 | 문서 아이콘 1종 | 상품·거래 자료, 적용 요건, 각 당사자 책임 확인 |
| 库存与系统对接 | 기록·데이터 아이콘 1종 | 조회 정보와 실제 연동 지원 범위 확인 |

네 아이콘과 실제 문장으로 작업을 설명한다. 사진처럼 보이는 새 창고, 소유 선박·트럭, 관제실, 자동화 라인, 가짜 WMS 화면을 만들지 않는다. 인증 도장·정부 문장·보안 방패를 IOR·통관 자격의 대체 이미지로 사용하지 않는다.

추후 추가 삽화가 필요해도 상자·라벨·문서처럼 일반적인 작업 요소만 다룬다. 구체적인 시설 배치나 자동 연동 성공을 묘사하지 않는다. 현재 목록에서는 생성 필요성이 없으므로 해당 제작을 예약하지 않는다. 사용자가 삭제한 히어로 안내·콘셉트 표식도 복원하지 않는다.

## 5. 실제 운영 증빙의 준비 목록

아래는 추가 확보·검토할 자료이며, 생성 이미지로 대체하지 않는다.

| 자료 | 필요한 확인 | 없을 때의 화면 |
| --- | --- | --- |
| 미국 창고 외부 또는 입고 구역 사진 1장 | 해당 시설과 PNPLINE 운영의 관계, 촬영 시점, 사용 권한, 위치 설명의 정확성 | 직영 운영과 화물 인계에 관한 V4 문단만 표시 |
| 실제 작업 사진 1장(선택) | 현재 제공 작업인지, 촬영 장소·시점, 사람·화물 표식의 공개 범위 | 입고·보관·피킹·출고 설명 유지 |
| 재고·입출고 기록 실화면 1장(선택) | 실제 고객에게 제공하는 기능, 권한·갱신 방식, 고객명·주소·이메일·주문번호 등의 제거 | 가용 기능과 범위를 상담에서 확인한다는 V4 문단 유지 |
| 자격·수치·고객 사례(선택) | 유효성, 기간·산정 근거, 공개 권한, 문구 검토 | 로고·수치·배지 모듈을 생략 |

수집 목록에서 `texas-facility-1.jpeg`, `texas-facility-2.webp`, `california-facility-1.webp`, `california-facility-2.webp`라는 원본 URL의 파일이 로컬에 있는 것은 확인했다. 파일명과 웹사이트 출처만으로 실제 시설 사진·현재 운영 사실·사용 권한을 확인한 것은 아니다. Toronto 자료는 미국 창고 증빙으로 사용하지 않는다.

공개할 증빙에는 내부 목록상 원본 경로/URL, 실제 촬영 여부, 시설·작업과의 관계, 확인일, 사용 권한, 공개 가능 범위, 마스킹 여부, 확인 담당, 승인 상태를 기록한다. 공개 화면에는 설명에 필요한 정확한 캡션만 표시한다. 확인되지 않은 항목은 실제 운영 증거로 노출하지 않는다.

기존 문서에 있는 AI 재구성 이미지 허용안보다 이번 사용자의 ‘실제 시설·장비·실적으로 오인될 이미지 금지’를 우선한다. 안내 라벨을 붙이면 된다는 이유로 재구성 증빙을 만들지 않는다.

## 6. 아이콘 공통 규칙

- 한 계열: Phosphor의 동일 선형 스타일을 기본으로 한다. 기존 패키지·사용 조건·정확한 아이콘 이름을 구현 시 확인하고 필요한 항목만 사용한다. 이번에는 설치·다운로드하지 않았다.
- 서비스 4종 외 UI 역할은 메뉴, 닫기, 이동 화살표, 선택 화살표, 펼침, 접힘, 오류 안내로 제한한다. 체크박스는 실제 입력 요소를 사용한다.
- 서비스 아이콘 24px, UI 아이콘 20px를 기준으로 한다. 클릭·터치 영역은 최소 44px로 확보한다.
- 아이콘만 보고 서비스를 추측하게 하지 않는다. 이름과 설명을 함께 둔다. 장식 아이콘은 보조기술에서 중복 낭독되지 않게 하고 아이콘 전용 버튼에는 동작 이름을 제공한다.
- 청록은 선택·주 행동에, 중성 색은 기본 상태에 사용한다. 오류·동의·열림 상태는 색뿐 아니라 문구·상태 정보로도 전달한다.
- 플랫폼·정부·인증 로고를 일반 기능 아이콘처럼 사용하지 않는다. 아이콘 확보는 생성 이미지 제작 수량에 포함하지 않지만 유료 라이선스가 필요해지면 구매 전에 별도로 알린다.

## 7. 히어로 인터랙션 명세

### 정상 동작

1. 중문 제목·설명·두 CTA는 영상 로딩과 독립적으로 표시한다.
2. 로딩 중에는 포스터를 보인다. 현재 포스터는 3.5초이고 영상 첫 시점은 다를 수 있으므로 같은 프레임이라고 간주하지 않는다. 최종 전달에서는 시작 프레임과 일치하는 포스터를 같은 영상에서 로컬 추출하는 것이 기본이다.
3. 히어로의 유효 스크롤 구간을 0~1의 진행도로 대응시킨다. 영상 준비 뒤 해당 진행도에 맞는 유효 시점으로 이동한다.
4. 아래 방향은 뒤 시점, 위 방향은 앞 시점으로 이동한다. 입력이 멈추면 마지막 요청 시점의 프레임을 표시한 뒤 유지한다. 시간 경과에 따른 자동 진행·loop·playbackRate 역재생을 쓰지 않는다.
5. 빠르게 스크롤한 경우 오래된 프레임 요청을 순서대로 모두 재생하지 않고 최신 목표 시점을 우선한다. 영상은 paused 상태를 유지한다.
6. 히어로 고정 구간이 끝나면 일반 서비스 본문이 이어진다. 역방향 재진입 시 현재 스크롤 위치에 맞는 프레임을 복원한다.
7. 실제 초·프레임 매핑은 최종 영상과 제작 명세에 연결한다. 기존 33초 값을 최종 S1~S7의 확정 길이로 취급하지 않는다. S1~S7 이름·해설표는 내부 정보다.

### 언제든 내용으로 이동

- 헤더 견적 → #quote, 헤더 서비스·히어로 서비스 → #services, 히어로 견적 → #quote.
- 이동은 영상 준비·전체 구간 종료·장면 수와 무관하다. 긴 히어로를 순차 재생하는 이동 애니메이션을 넣지 않는다.
- 목적지 제목이 고정 헤더에 가려지지 않게 하고 키보드 포커스도 목적지에서 이어진다.
- 영상 로딩 실패가 페이지 전체 스크롤·링크·폼을 차단하지 않는다. 영상 위 레이어가 버튼의 클릭·터치를 가로채지 않도록 한다.
- 메뉴·FAQ·폼은 히어로의 렌더링 상태와 분리한다. 히어로 밖에서는 불필요한 시킹 처리를 멈춘다.

### 미디어 전달 항목

최종 영상 경로·버전, 실제 duration·fps·해상도·파일 크기, 시점 매핑, 포스터 시점, 데스크톱·모바일 텍스트 안전 영역, 모바일 대응 파일 유무, 출처를 함께 기록한다. 이번 단계에서는 새 인코딩이나 영상 교체를 실행하지 않았다.

## 9. 비용·생성 수량 관리

[생성 비용 기록](pnpline-generation-budget-2026-11-01.json)을 이번 사용자 한도 지시 이후의 신규 에셋 생성 원장으로 사용한다. 과거 비용·이미지 수량은 미집계로 별도 표시하며 이를 새 지출 $0과 혼동하지 않는다.

| 계획 | 신규 생성 이미지 | 추가 생성 비용 |
| --- | --- | --- |
| 기존 영상·포스터·로고·폰트 재사용 | 0장 | $0 |
| 작업 설명·일반 기능 아이콘 | 0장 | $0의 생성 비용. 아이콘 구매는 계획하지 않음 |
| 실제 창고·시스템 자료 | 0장 | 생성으로 보완하지 않음 |
| 이번 기본안 합계 | **0장** | **$0** |

향후 유료 생성이 실제로 필요해지면 매 호출 전에 도구·모델·해상도·수량·단가·이번 요청 최대 예상액·기존 누적액·호출 후 예상 누적액·호출 후 이미지 수를 먼저 제시한다. 현재 호출할 도구를 정하지 않았으므로 임의 단가를 쓰지 않는다.

비용은 이미지뿐 아니라 새 영상·편집·업스케일 등 유료 생성 전반을 합산한다. 여러 도구나 시안별로 나눠 한도를 새로 시작하지 않는다. 이미 발생한 금액과 실행 중 예약 금액을 함께 계산한다. 실패·재시도에도 과금이 있다면 포함하고, 무료 출력도 생성 이미지 수에는 포함한다. 여러 변형을 반환하는 요청은 최대 반환 장수로 사전 계산한다.

**다음 호출로 예상 누적 비용이 $1를 초과하거나 생성 이미지가 10장을 초과하면, 실행 전에 사용자의 확인을 받는다.** 정확히 $1 또는 10장에 도달한 뒤에도 다음 호출을 자동 진행하지 않는다. 가격·최대 출력 수가 불명확해 한도 내인지 보장할 수 없으면 먼저 확인한다. 이미지 생성 제한은 대화를 나누거나 날짜가 바뀌었다고 초기화하지 않는다.

유료 생성 전 확인이 필요한 이유는 이번 사용자가 직접 지정한 $1·10장 한도다. 현재 기본안은 추가 생성이 없으므로 비용 승인 질문 없이 목록 작성을 완료한다.
