# PNPLINE 간체 중국어 로컬라이징 및 바이두 SEO 전략

## 목적과 기준

기준일: 2026-09-11  
근거 문서: `pnpline-cn-plan_1.docx` 2026-09-09 v1

`pnpline.cn`은 중국의 크로스보더 셀러가 `美国海外仓`, `FBA头程`, `IOR进口商`을 검색할 때 도달해 견적 또는 상담으로 이어지도록 설계합니다. 한국어 사이트를 간체 중국어로 번역하거나, 한국 출발 미국 도착만을 전제로 카피를 작성하지 않습니다.

중국 사이트의 전체 포지셔닝은 아래 문구를 기준으로 합니다.

> `韩资美国自营仓 · 合规 IOR 清关 · 韩美中三地一体运营`

이 포지셔닝은 실제로 확인 가능한 운영 사실에만 사용합니다. Gardena(CA)·Katy(TX) 직영 창고, 자사 IOR·Bond, Codiz 기반 WMS, 법인과 주소는 페이지 공개 전에 운영팀이 증빙을 확인해야 합니다.

## 핵심 페이지 카피 기준

### 홈

- 메타 타이틀: `美国海外仓、IOR清关与跨境电商履约 | PNPLINE`
- 메타 디스크립션: `PNPLINE提供美国自营海外仓、FBA中转补货、一件代发、IOR进口商服务与清关支持。以真实仓库、合规流程和WMS系统服务中国跨境卖家。`
- 첫 화면: 실제 창고 사진, 즉시 견적 CTA, `工厂 → 头程 → 清关 → 美国仓 → 尾程` 흐름을 사용합니다.
- 신뢰 블록: 실제 창고 주소·면적·도크·처리 능력, IOR·Bond, WMS 화면, 확인된 처리 실적만 표시합니다.

### 一件代发

- 비용을 `头程运输费 / 仓储费 / 操作处理费 / 尾程派送费`로 나눠 설명합니다.
- 장기 보관료, 최소 과금, 추가 작업 비용의 적용 조건을 숨기지 않습니다.
- Shopify, TikTok, Amazon API 연동은 실제 지원 범위와 연결 방식으로만 표시합니다.

### IOR进口商服务

- IOR 번호, Form 5106, CTPAT 등 정책·규정은 게시일과 최종 검수일을 표시합니다.
- `EIN`, `POA授权委托书`, `Bond担保保单`, `COO原产地证`, 보관 문서 등 자가 점검 항목을 제공합니다.
- PNP Line이 수입자 역할을 맡는 범위와 화주 책임의 경계를 명확히 씁니다.
- 공개 전 미국 통관팀의 법률·실무 사실 검수가 필수입니다.

### 自营仓库实景

- Gardena와 Katy의 외관, 간판, 랙, 작업장, 출고장 등 실제 사진을 창고별 8~12장 사용합니다.
- 지도, 실제 주소, 항만·공항과의 거리, 시설 수치, 법인·보험 증빙을 제공합니다.
- 스톡 사진이나 생성 이미지를 실제 시설 사진처럼 사용하지 않습니다.

### 가격과 견적

- 구간 요율과 비용 항목은 공개하고, 화물 특성에 따라 달라지는 최종 가격은 견적으로 안내합니다.
- 견적 예시는 최소 두 건을 제공합니다. 예: Amazon 20CBM, 독립몰 월 500건.
- 견적 응답 SLA를 표시하고, 실제로 지킬 수 있는 시간만 약속합니다.

## 전환 설계

중국 B2B의 기본 상담 채널은 WeChat입니다. 다만 실시간 중국어 응대가 가능한 경우에만 모든 페이지의 플로팅 버튼과 푸터에 기업 WeChat QR을 둡니다. 응대 인력이 없으면 QR을 방치하지 말고 폼·이메일 중심으로 운영하며, 자동 회신에 24시간 회신 약속과 담당 채널을 명시합니다.

견적 폼은 다음 순서로 6개를 넘기지 않습니다.

1. `产品类目`
2. `发货方式` (`海运整柜 / 拼箱 / 空运 / 未定`)
3. `月出货量`
4. `目的地` (`FBA仓代码 / PNPLINE仓库 / 最终消费者`)
5. `是否需要IOR` (`是 / 否 / 不清楚`)
6. `微信号或手机号码`

## 바이두와 기술 구현

- `lang="zh-CN"`을 사용하고, `pnpline.cn`의 각 페이지는 자기 자신을 canonical로 설정합니다.
- `.cn`은 독립 운영합니다. `.co.kr`·`.com`과 무리하게 `hreflang`을 연결하지 않습니다.
- Baidu Webmaster Tools에 등록하고 `sitemap.xml`과 快速收录 API를 연결합니다.
- Organization, Service, FAQPage JSON-LD를 구현합니다.
- 모바일 첫 화면은 1.5초 이내를 목표로 하며, WebP, 지연 로딩, 최소 JavaScript를 적용합니다.
- 시스템 폰트 스택 `PingFang SC, Microsoft YaHei, system-ui` 또는 자체 호스팅 서브셋 폰트를 사용합니다.
- Google Fonts, Google Analytics, Google Tag Manager, reCAPTCHA, YouTube, Facebook Pixel, cdnjs·googleapis 기반 외부 jQuery는 제거하거나 중국 내 사용 가능한 대안으로 교체합니다.
- 분석은 百度统计, 캡차는 자체 구현 또는 알리클라우드 验证码를 사용합니다.

## 실행 순서

1. ICP 备案과 도메인 명의·실명 인증을 우선 확인합니다.
2. 창고 실사진·영상과 법인·보험·IOR·Bond 증빙을 확보합니다.
3. 百度指数와 5118로 키워드 검색량을 실측해 우선순위와 카피를 보정합니다.
4. MVP 10페이지의 메타, H1, 섹션 카피, FAQ, 폼, 구조화 데이터를 확정합니다.
5. IOR·T86 정책 해설은 사이트 오픈 전에도 知乎와 公众号에 발행하고, 오픈 후 정식 URL로 옮깁니다.
6. 바이두 색인과 문의 데이터를 매주 점검해 P1·P2 페이지와 콘텐츠 주제를 확대합니다.
