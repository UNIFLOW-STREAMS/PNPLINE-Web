# 홈 scroll-world 카메라와 장면 여정

## Type

`wayfinder:grilling`

## Status

Resolved

## Question

사용자가 스크롤할 때 어떤 카메라 방식과 장면 순서로 물류 여정을 경험하게 할 것인가?

## Decision so far

미니어처 물류 세계 안에서 카메라가 한 방향으로 계속 전진하는 방식을 채택한다. 항구에서 운송, 미국 입고, 보관, 주문 처리, 출고로 이어지는 흐름이 하나의 연결된 세계처럼 보이도록 설계한다. 장면 전환 때 카메라가 뒤로 튀거나 방향을 급격히 바꾸지 않도록 한다.

## Decision

장면은 다음 6단계로 구성한다.

1. 중국 상품 출발
2. 국제 운송
3. 미국 도착 및 입고 준비
4. 미국 창고 입고·보관
5. 주문 처리·피킹·패킹
6. FBA 입고 또는 최종 배송 출고

장면은 서비스 약속이나 확인되지 않은 운영 수치를 표현하는 대신, 고객 상품의 물류 여정을 이해시키는 상징적 흐름으로 구성한다.

## Blocked by

홈 scroll-world 미술 방향
