# 출시 순서와 홈 경험 구조

## Type

`wayfinder:task`

## Status

Resolved

## Question

32개 페이지를 어떤 순서와 홈 경험으로 공개할 것인가?

## Decision

핵심 10개 페이지와 개인정보 페이지를 MVP로 먼저 준비하고, 이후 P1·P2 페이지를 단계적으로 추가한다. 홈 상단은 5~7개 장면의 scroll-world로 브랜드 경험을 만들고, 그 아래에 기존 방식의 서비스 증빙, 비용 안내, FAQ, 견적 폼을 배치한다.

## Rationale

홈의 차별화와 B2B 고객의 검토 흐름을 함께 확보한다. 인터랙션만 강조하면 신뢰 정보가 늦어지고, 일반적인 랜딩만 만들면 사용자가 기대한 시각적 차별성이 약해진다.
