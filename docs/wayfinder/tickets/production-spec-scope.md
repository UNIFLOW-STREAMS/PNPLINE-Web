# 제작 명세의 목표와 범위

## Type

`wayfinder:task`

## Status

Resolved

## Question

중국어 웹사이트 제작 전에 어느 수준까지 명세를 확정할 것인가?

## Decision

32개 전 페이지를 대상으로 콘텐츠, 중국어 SEO, IA, 디자인, 인터랙션, 기술 구조, placeholder 정책, QA, 공개 기준을 포함한 전체 제작 명세를 만든다.

## Rationale

페이지별 콘텐츠와 설계가 분리되면 개발 중에 중국어 카피, 운영 데이터, SEO 구조가 다시 흔들릴 수 있다. 개발자가 바로 착수할 수 있는 하나의 전달 기준이 필요하다.
