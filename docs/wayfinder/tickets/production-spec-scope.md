# 제작 명세의 목표와 범위

## Status

Resolved — 2026-10-31 사용자 지시 `MVP-2PAGE-20261031`로 갱신.

## Decision

메인 랜딩 `/`와 개인정보 처리방침 `/privacy/` 두 공개 콘텐츠 경로를 대상으로 카피·IA·디자인·Scroll World·기술·운영 데이터·SEO·QA·공개 기준을 확정한다. 기존 32페이지는 원자료로 보존한다. 26개 페이지의 핵심 내용은 랜딩에 통합하고 뉴스/정책 3개와 파트너 1개는 보류한다. 상세 전문과 별도 경로는 MVP 완료 조건이 아니다.

기준: [MVP 범위와 32개 대응표](../../mvp-single-page-scope.md). 기존 32개 전 페이지 명세 요구를 이번 범위에서 대체한다. 실제 콘텐츠·미디어·개인정보·출시 승인은 각 실행 이슈에서 확인한다.
