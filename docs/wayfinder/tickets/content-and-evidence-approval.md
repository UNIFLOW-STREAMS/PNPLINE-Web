# 콘텐츠와 증빙 승인

## Type

`wayfinder:task`

## Status

Resolved

## Question

중국어 카피와 실제 운영 자료를 누가 어떤 기준으로 승인할 것인가?

## Decision

페이지별 중국어 카피와 운영 정보는 다음 4단계로 승인한다.

1. 중국 시장용 SEO 초안 작성
2. 중국어 원어민 또는 전문 번역자 검수
3. PNPLINE 담당자의 서비스 사실 확인
4. 법무·규제 문구 최종 확인

주소·창고 수치·가격·처리 시간·IOR·Bond·통관·FDA·FCC·De Minimis·T86 관련 문구는 출처가 확인된 경우에만 공개한다. 자료가 없는 블록은 숨기고, AI 재구성 이미지는 설명용 자료라는 표기를 붙인다.

## Evidence display decision

증빙 자료는 상태를 구분해 공개한다. 확인된 실제 사진·문서·수치는 실제 자료로 표시하고, 기존 자료를 바탕으로 만든 AI 재구성 이미지는 概念示意 또는 资料重构示意라고 표시한다. 확인되지 않은 주소, 수치, 서비스 범위와 자격 정보는 공개하지 않고 해당 블록을 숨긴다.

## Evidence manifest decision

증빙 자료는 별도 JSON manifest로 관리한다. 각 항목에 출처, 확인일, 사용 권한, 적용 페이지, 승인 상태, 자료 유형을 기록한다. 페이지는 승인 상태인 자료만 불러오며, 실제 자료와 자료 기반 재구성 자료를 기술적으로 구분한다.

## Evidence label decision

실제 자료에는 实景资料 또는 已核实资料 라벨을 표시하고, 자료 기반 AI 재구성 이미지에는 概念示意 또는 资料重构示意 라벨을 이미지 가까이에 표시한다. 내부 출처 정보와 승인 기록은 화면에 노출하지 않고 manifest에서 관리한다.

## Consent display decision

견적 폼에는 필수 개인정보 동의 체크박스를 둔다. 폼에서 수집 목적, 수집 항목, 12개월 보관 기준, 이메일 알림, 데이터 저장 방식, 삭제 요청 방법을 간단히 안내하고, 자세한 내용은 중국어 개인정보 페이지로 연결한다. 최종 중국어 문구는 법무 검토 후 확정한다.

## Language scope decision

중국어판은 중국 본토 고객을 위한 간체 중국어 단일 언어로 제공한다. 중국어판 안에서는 자동 언어 감지를 사용하지 않고, 한국어 사이트는 별도로 유지한다.

## Blocked by

운영 담당자와 중국어 검수자의 확정
