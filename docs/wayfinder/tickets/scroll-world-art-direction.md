# 홈 scroll-world 미술 방향

## Type

`wayfinder:grilling`

## Status

Resolved

## Question

홈의 상징적 물류 세계를 어떤 미술 방향으로 만들 것인가?

## Decision

정밀 산업형 미니어처 디오라마를 채택한다. 작은 모형처럼 보이지만 장난감스럽지 않게 만들고, 창고 랙·패키지·컨테이너·항공·배송 경로를 정교한 산업 구조로 표현한다. 다만 첨부된 miniature 참고 이미지는 질감과 공간감을 이해하기 위한 참고자료일 뿐, 최종 스타일을 그대로 복제해야 하는 지시가 아니다.

워터마크가 있는 참고 이미지 자체는 공개 사이트의 자산으로 사용하지 않는다. 최종 비주얼은 PNPLINE의 브랜드 시스템과 중국어권 B2B 고객의 신뢰감에 맞춰 별도로 제작한다.

## Why this matters

미술 방향을 먼저 정해야 카메라 이동, 장면 연결 방식, 생성 이미지의 스타일 프롬프트, 영상 예산을 안정적으로 결정할 수 있다.
