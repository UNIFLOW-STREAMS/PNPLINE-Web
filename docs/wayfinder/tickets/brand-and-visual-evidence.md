# 중국어 브랜드 시스템과 시각 자료 경계

## Type

`wayfinder:task`

## Status

Resolved

## Question

기존 브랜드를 중국어 사이트에 어떻게 적용하고 AI 생성 이미지를 어디까지 사용할 것인가?

## Decision

PNPLINE 로고와 핵심 색상은 유지한다. 중국어권 디지털 사용성을 고려한 별도 디자인 시스템을 만든다. AI 생성 비주얼은 홈의 상징적 물류 세계와 전환 장면에 사용한다. 창고·자격·서비스 증빙은 실제 자료를 우선한다. 실제 자료가 부족해 기존 자료를 바탕으로 AI 재구성 이미지를 만들더라도 `概念示意` 또는 이에 준하는 표기를 하고, 실제 시설 사진이나 공식 증명서처럼 사용하지 않는다.

## Rationale

홈에는 기억에 남는 상징적 경험이 필요하지만, 증빙 영역에서는 사실성과 출처가 더 중요하다. 두 목적을 같은 이미지 체계로 처리하면 중국어권 B2B 고객의 신뢰를 해칠 수 있다.
