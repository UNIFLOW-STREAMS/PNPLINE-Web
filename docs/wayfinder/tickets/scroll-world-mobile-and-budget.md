# 모바일 전략과 미디어 예산

## Type

`wayfinder:grilling`

## Status

Resolved

## Question

모바일에서 scroll-world를 어떻게 제공하고, 생성·렌더링 비용을 어디까지 허용할 것인가?

## Decision so far

데스크톱용 가로 영상과 모바일용 세로 영상을 각각 제작한다. 데스크톱 영상을 모바일 화면에 단순히 잘라 넣지 않고, 세로 화면의 구도와 피사체 위치에 맞춰 별도의 영상 체인을 만든다.

## Decision

제작은 단계별로 승인한다.

1. 대표 장면 1개를 데스크톱·모바일용으로 시험 제작한다.
2. 품질·비용·로딩 성능을 확인한 뒤 2개 장면 파일럿을 제작한다.
3. 파일럿을 승인하면 나머지 4개 장면을 제작한다.

모션 감소 설정에서는 영상 대신 정적 장면과 일반 콘텐츠로 전환한다. 실제 지출 상한과 사용할 생성 도구는 별도 확인 후 정하며, 그 전에는 전체 미디어를 생성하지 않는다.

## Blocked by

홈 scroll-world 미술 방향
홈 scroll-world 카메라와 장면 여정
