# 홈 scroll-world 영상 컨셉·키 비주얼·스타일 가이드

## Type

`wayfinder:grilling`

## Status

Open

## Question

정밀 산업형 미니어처 디오라마라는 확정된 미술 방향을, 6개 물류 장면에서 어떤 영상 컨셉과 키 비주얼로 일관되게 구현할 것인가?

## Scope

- scroll-world 전체를 대표하는 영상 컨셉과 첫 장면의 히어로 키 비주얼을 정한다.
- 6개 장면의 조명, 재질, 축척, 색 보정, 인물 밀도, 카메라 렌즈감과 전환 규칙을 정한다.
- 데스크톱과 모바일에서 각 장면을 어떻게 재구도할지 정한다.
- 실제 PNPLINE 시설이나 운영 사실을 증빙하는 것처럼 보이지 않도록, 생성 비주얼의 표현 경계와 금지 요소를 정한다.

## Preconditions

- 정밀 산업형 미니어처 디오라마를 사용한다.
- 카메라는 중국 상품 출발부터 미국 최종 배송까지 한 방향으로 전진한다.
- 여정은 중국 상품 출발, 국제 운송, 미국 도착·입고 준비, 창고 입고·보관, 주문 처리·피킹·패킹, FBA 입고 또는 최종 배송 출고의 6단계다.
- 데스크톱 가로형과 모바일 세로형 미디어는 별도로 제작한다.

## Design-tree frontier

❓ **Q1** - **대표 키 비주얼**: 첫 화면에서 무엇을 스크롤 세계의 대표 이미지로 삼을 것인가? 항구·컨테이너를 중심으로 한 출발 장면, 창고와 주문 처리까지 한 프레임에 암시하는 넓은 세계 장면, 혹은 이동 경로가 강조된 공중 디오라마 중 하나를 선택한다.

➡️ 항구에서 시작해 멀리 연결되는 창고·운송 경로를 암시하는 넓은 출발 장면을 권장한다. 6단계 여정의 첫 장면을 정확히 보여 주면서도, 뒤에 펼쳐질 세계를 약속할 수 있다.

❓ **Q2** - **시각 문법**: 미니어처 세계의 조명·재질·색 보정·인물 밀도를 어느 정도 현실적으로 유지할 것인가?

➡️ 브랜드 네이비·그린을 길찾기, 패키지 테이프, 조명 포인트에 절제해 사용하고, 자연광 기반의 차분한 산업 조명, 금속·크라프트지·콘크리트 중심의 사실적 재질, 작업 흐름을 읽게 하는 소수의 인물을 권장한다. 장난감 질감, 과장된 미니 피규어, 네온·보라색·공상과학 연출은 배제한다.

❓ **Q3** - **카메라와 재구도 규칙**: 전진 카메라가 장면을 통과할 때 어떤 렌즈감·속도·전환 방식을 쓰며, 모바일은 무엇을 재구도할 것인가?

➡️ 중간 광각의 완만한 전진과 전경 피사체를 활용한 자연스러운 가림 전환을 권장한다. 급격한 회전·후진·줌은 피하고, 모바일에서는 같은 이야기 단위를 유지한 채 주 피사체와 진행 경로를 화면 중앙 세로 축에 다시 배치한다.

## Deliverables

1. 출처·사용 권한을 기록한 무드보드
2. 대표 장면 스타일프레임 2~3안과 키 비주얼 후보
3. 선택안 기반 6개 장면 키프레임
4. 장면 순서·카메라 이동·전환을 검수할 스크롤 애니매틱
5. 데스크톱·모바일 대표 장면 파일럿
6. 생성 프롬프트 가이드, 금지 요소, 장면별 구도·전환 규칙

## Completion criteria

- 대표 키 비주얼과 단일 영상 컨셉이 승인됐다.
- 6개 장면 키프레임이 하나의 미술·카메라 문법으로 검수됐다.
- 데스크톱·모바일 파일럿이 의도한 구도와 브랜드·증빙 경계를 충족한다.
- 미디어 전달 명세를 작성하는 데 필요한 장면 수, 구도, 재구도 원칙과 애니매틱 길이가 확정됐다.
