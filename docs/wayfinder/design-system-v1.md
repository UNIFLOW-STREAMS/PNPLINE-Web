# PNPLINE 중국어 디자인 시스템 V1

## 문서 상태

- 연결 이슈: [#25 중국어 디자인 시스템과 핵심 화면 승인](https://github.com/UNIFLOW-STREAMS/PNPLINE-Web/issues/25)
- 기준 콘셉트: `output/design-concept-v1/`
- 대상 도메인: `https://pnpline.cn`
- 대상 언어: 간체 중국어(`zh-CN`)
- 상태: 개발 전달용 초안

이 문서는 기존 6개 홈페이지 콘셉트를 실제 UI 구현에 전달하기 위한 공통 토큰, 컴포넌트, 화면 구조와 검수 기준을 정의한다. 콘셉트 이미지는 방향을 보여 주는 자료이며, 이미지 안의 글자·수치·시설 표현을 실제 운영 사실로 사용하지 않는다.

## 디자인 원칙

1. **운영 신뢰 우선**: 미국 창고, 자격, 서비스 증빙은 확인된 실제 자료를 우선한다. 자료 기반 AI 재구성은 `资料重构示意` 또는 `概念示意`로 표시하고 증빙 사진처럼 사용하지 않는다.
2. **B2B 스캔성**: 한 화면에서 서비스 범위, 적용 조건, 다음 행동을 빠르게 파악할 수 있도록 제목·근거·CTA의 순서를 고정한다.
3. **상징과 사실의 분리**: 홈의 scroll-world는 PNPLINE의 물류 흐름을 상징적으로 표현하고, 시설·가격·규제·SLA 영역은 검수된 콘텐츠 컴포넌트로 표현한다.
4. **중국어 우선**: 중국어 문장의 줄바꿈과 버튼 폭을 기준으로 설계한다. 영문 브랜드명과 물류 약어는 보조 표기로 사용한다.
5. **점진적 공개**: 미확정 운영 데이터는 빈 카드나 `TBD`로 노출하지 않고 JSON 상태값에 따라 해당 블록을 숨긴다.

## 토큰 구조

토큰은 `primitive → semantic → component` 3계층으로 관리한다.

- CSS 원본: [`output/design-concept-v1/design-tokens.css`](../../output/design-concept-v1/design-tokens.css)
- Primitive: 색상, 폰트, 간격, 반경, 그림자처럼 직접 값을 갖는 토큰
- Semantic: 페이지 배경, 본문, 액션, 테두리처럼 용도를 설명하는 토큰
- Component: 헤더 높이, 버튼 높이, 입력 높이, 콘텐츠 최대 폭처럼 컴포넌트가 사용하는 토큰

### 색상

| 용도 | 토큰 | 값 |
| --- | --- | --- |
| 본문 잉크 | `--text-primary` | `#182C39` |
| 보조 본문 | `--text-secondary` | `#40545D` |
| 공식 브랜드 원색 | `--brand-primary` | `#00ABE1` |
| 주 CTA | `--action-primary` | `#007FA8` |
| 밝은 브랜드 배경 | `--surface-tinted` | `#DFF6FD` |
| 역상 배경 | `--surface-inverse` | `#182C39` |
| 성공·검증 상태 | `--status-success` | `#1A7F4B` |
| 경고 | `--color-signal-amber` | `#BF6F1D` |
| 오류 | `--color-signal-red` | `#B83A36` |
| 정보 | `--color-signal-blue` | `#236C91` |

공식 브랜드 원색은 `#00ABE1`이다. 흰색과의 대비가 2.65:1이므로 작은 텍스트나 흰색 글자의 CTA 배경으로 직접 사용하지 않는다. 주요 CTA와 키보드 포커스에는 흰색과 4.56:1 대비를 갖는 파생색 `#007FA8`을 사용한다. 공식 원색은 큰 비텍스트 그래픽, 장식 강조, 또는 잉크색 텍스트와 함께 사용한다. 성공·검증 상태는 브랜드 블루와 혼동되지 않도록 별도 녹색 신호 토큰을 사용하고, 정보·경고·오류도 각각의 신호색을 유지한다.

기본 중국어 글꼴은 `Noto Sans SC`, `PingFang SC`, `Microsoft YaHei` 순서로 지정한다. 영문 PNPLINE과 숫자는 라틴 산세리프를 사용할 수 있지만, 한 컴포넌트 안에서 중국어와 영문의 기준선이 흔들리지 않도록 한다.

### 레이아웃

- 콘텐츠 최대 폭: `1200px`
- 데스크톱 좌우 여백: 최소 `40px`
- 모바일 좌우 여백: `16px`
- 기본 간격: 4px 단위, 주요 섹션 간격은 64~96px
- 기본 반경: 0, 4, 8px만 사용
- 기본 버튼·입력 터치 높이: 최소 44px

## 공통 컴포넌트

### Header / Navigation

- 데스크톱: 좌측 PNPLINE 워드마크, 중앙 또는 우측에 서비스·解决方案·资源·关于我们, 우측 주 CTA
- 모바일: 워드마크, 메뉴 버튼, 고정 하단 또는 메뉴 내부의 견적 CTA
- 대표 URL과 내부 링크는 `https://pnpline.cn` 기준으로 생성한다.
- 활성 메뉴는 접근성용 브랜드 블루(`--action-primary`) 텍스트와 2px 하단선으로 표시한다.

### Button

| 변형 | 용도 | 기본 | Hover/Focus | Disabled |
| --- | --- | --- | --- | --- |
| Primary | 견적·문의·주요 전환 | 접근성용 브랜드 블루 배경/흰색 글자 | 잉크 배경/흰색 글자 | 연한 잉크/회색 글자 |
| Secondary | 상세 보기·보조 이동 | 투명/잉크 테두리 | 연한 브랜드 배경 | 연한 테두리 |
| Text | 섹션 내 관련 링크 | 잉크 텍스트/화살표 | 접근성용 브랜드 블루 텍스트 | 회색 텍스트 |

버튼 텍스트는 중국어 기준으로 `获取报价`, `了解服务`, `查看详情`, `提交咨询`처럼 동작을 직접 표현한다. 아이콘만으로 의미를 전달할 수 있는 경우에는 텍스트를 중복하지 않는다.

### Evidence Badge

- `已核实资料`: 확인된 실제 자료
- `资料重构示意`: 기존 자료를 바탕으로 재구성한 이미지
- `概念示意`: 상징적·설명용 생성 이미지
- `暂不公开`: 운영 데이터가 확정되지 않아 숨긴 블록

배지는 사진 위에 겹치지 않고 사진 하단의 캡션 영역에 둔다. 주소·면적·처리량·자격번호를 실제로 확인하기 전에는 문구나 시각 요소로 추정하게 만들지 않는다.

### FAQ

- 질문 행 전체가 키보드로 열리고 닫혀야 한다.
- 열린 항목은 한 번에 여러 개 허용하되, 페이지 이동 없이 답변을 읽을 수 있어야 한다.
- FAQPage JSON-LD는 화면에 실제로 노출된 질문과 답변에만 사용한다.

### Quote Form

필수 입력은 서비스 유형, 판매 채널, 예상 월 물량, 연락처, 개인정보 동의로 제한한다. 확정되지 않은 WeChat 상담 채널은 노출하지 않고 이메일·견적 폼으로 대체한다.

상태는 `입력 중 → 제출 중 → 접수 완료 → 제출 실패`를 제공한다. 실패 시 입력값을 보존하고 재시도 방법을 보여 준다. 성공 문구는 “已收到您的咨询，我们会根据您提交的信息与您联系。”처럼 확정되지 않은 응답 시간을 약속하지 않는다.

## 핵심 화면 명세

### 01. Home / Hero

- 목적: 중국 셀러에게 미국 해외창고·통관·주문 이행의 전체 흐름을 첫 화면에서 전달
- 미디어: scroll-world 대표 장면. 실제 시설 증빙이 아니라 상징적 물류 세계로 라벨링
- CTA: `获取报价`, `了解服务`
- 다음 섹션 신호: 서비스 선택 영역의 상단이 첫 화면 하단에 일부 보이도록 구성
- 모션 감소: 대표 정적 이미지와 동일한 핵심 카피로 대체

### 02. Services / Service Selector

- 3PL 해외창고, 국제운송, 통관·合规, 退货与回收을 동일한 구조로 비교
- 각 항목은 한 줄 설명, 적용 대상, 상세 링크, 증빙 상태를 포함
- 아코디언은 모바일에서 기본 닫힘, 데스크톱에서는 첫 항목만 기본 열림
- 서비스 약속과 가격 숫자는 승인된 콘텐츠 데이터가 있을 때만 노출

### 03. Logistics Network

- 지도처럼 보이는 지리 실루엣 대신 `仁川 → 美国进口清关 → 加利福尼亚 / 德克萨斯` 비지리적 업무 도식 사용
- 실제 운송 경로·소요 기간·창고 간 이동을 암시하는 선형 수치는 넣지 않음
- 노드별 설명은 `集货与发运`, `美国进口清关`, `自营海外仓` 수준으로 제한

### 04. Sales Channels

- Amazon, Shopify, TikTok Shop, 미국 유통 채널을 서비스 탐색 진입점으로 제공
- 로고는 사용 권한이 확인된 공식 자산만 사용
- 채널별 상세 페이지가 없거나 지원 범위가 미확정이면 해당 카드를 숨김

### 05. Platform / WMS

- 재고 조회, 출고 지시, 주문 상태 등 확인된 WMS 기능만 소개
- UI 캡처가 실제 운영 화면이 아니면 `概念示意` 표기
- 시스템 수치·실시간 상태·API 지원 범위는 운영 데이터가 확정된 경우만 표시

### 06. Quote / Contact

- 긴 설명보다 서비스 선택과 연락처 입력을 우선
- 모바일에서는 한 열 폼, 데스크톱에서는 입력 영역과 상담 안내를 2열로 배치
- 개인정보 동의 전문 링크는 폼 제출 버튼 근처에 고정
- WeChat QR은 실제 담당자와 채널이 승인된 뒤에만 추가

## 반응형 기준

| 구간 | 기준 |
| --- | --- |
| 360~767px | 모바일 전용 세로 미디어, 한 열 레이아웃, 가로 스크롤 금지 |
| 768~1199px | 태블릿·소형 데스크톱, 2열 콘텐츠, 축소된 scroll-world |
| 1200px 이상 | 전체 6개 섹션, 1200px 콘텐츠 폭, 대형 미디어와 여백 |

데스크톱·모바일 영상은 별도 자산으로 관리한다. 화면 비율을 억지로 맞추기 위해 중요한 물류 객체를 잘라내지 않는다.

## 접근성·성능 기준

- 본문과 CTA는 WCAG AA 대비를 목표로 한다.
- 모든 이미지에 실제 의미를 반영한 중국어 alt를 작성하고, 장식 이미지는 빈 alt를 사용한다.
- 키보드 포커스는 `--shadow-focus`로 명확히 표시한다.
- 첫 장면과 다음 장면만 우선 로딩하고, 나머지 미디어는 지연 로딩한다.
- `prefers-reduced-motion: reduce`에서는 영상 시킹을 중지하고 정적 fallback을 사용한다.
- 모바일 초기 화면에서 CTA와 핵심 카피가 미디어 로딩보다 먼저 표시되어야 한다.

## 승인 체크리스트

- [ ] 중국어 폰트와 줄바꿈이 홈·서비스·견적 화면에서 안정적이다.
- [ ] 실제 자료·AI 재구성·개념 이미지의 라벨이 화면 구조에서 구분된다.
- [ ] 미확정 운영 데이터가 `TBD` 또는 추정 수치로 노출되지 않는다.
- [ ] 데스크톱과 모바일의 핵심 화면이 각각 검토 가능하다.
- [ ] CTA, 입력, 오류, 성공, disabled 상태가 정의되어 있다.
- [ ] `https://pnpline.cn`이 대표 주소이며 `www` 301 규칙이 링크·공유·SEO 명세와 일치한다.
- [ ] 디자인 승인 결과와 수정 사항을 #25 댓글에 기록한다.
