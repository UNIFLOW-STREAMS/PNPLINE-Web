# #61 브랜드 강조형 미니어처 — Codex 전달 패키지

## 구성

- `issue-61-codex-prompt.md`: 수정된 전체 작업 지시서.
- `references/brand-miniature-style-b.png`: 첫 번째 사용자 첨부. 공간·재질·깊이·브랜드 강조 방식의 참고 이미지.
- `references/PNP-LINE.webp`: 두 번째 사용자 첨부. 이번 작업에 사용할 로고 원본.
- `INPUT-ASSETS.json`: 입력 파일의 역할·크기·원본 해시와 지시서 버전 정보.

## 전달 방법

압축을 풀어 Markdown과 `references/`를 함께 Codex가 읽을 수 있는 작업 위치에 둔다. 전체 지시서를 전달하고 그 위치를 지정한다. 이 파일들이 이미 레포에 있거나 ChatGPT 첨부가 Codex에 자동 공유된다고 가정하지 않는다.

작업 지시서는 밝은 낮의 산업형 미니어처를 유지하면서, 공식 PNPLINE 로고가 컨테이너·창고·운송 수단 등에서 명확히 읽히는 브랜드 강조형 방향으로 수정했다. 첫 이미지의 녹색과 임의 심벌은 채택하지 않는다. 공식 로고는 두 번째 원본의 형태·색·비례를 보존해 합성한다.

## 경계

이 패키지에는 작업 지시서와 사용자가 제공한 두 원본만 있다. 새 스타일프레임·키프레임·영상은 만들지 않았다. 원본 이미지도 수정하지 않았다. GitHub 이슈·댓글·레포는 변경하지 않았다.

#61은 콘셉트 패키지와 저해상도 전환 검토를 담당한다. 실제 2장면 영상 파일럿은 #24, 최종 전달 명세는 #62, 홈 구현은 #42의 범위다. 실행 전에 연결 이슈와 실제 저장소 지침을 다시 확인한다.

사용자 제공 원본을 다시 전달하는 패키지이며 외부 공개용 자산 묶음이 아니다. 스타일 참고 권한을 공개 저장소 커밋·재배포 권한으로 확대하지 않는다.
