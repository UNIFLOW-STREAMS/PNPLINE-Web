## 현재 출발점

- 공개 범위는 메인 랜딩 `/`와 별도 개인정보 처리방침 `/privacy/`다.
- 콘텐츠 기준은 `docs/pnpline-china-source-content/pnpline-landing-mvp-copy-v4.zh-CN.md`다.
- `output/landing-wireframe-v4/index.html`에서 8개 섹션, 내부 앵커, 단일 견적 폼, 스크롤에 대응하는 영상 시점 이동을 검토했다.
- 실제 작업 영상을 연결한 스크롤 동작과 320~1440px 반응형 검증 기록은 `output/landing-wireframe-v4/qa/verification.md`에 있다.
- PNPLINE 로고와 기존 브랜드 시안 `#00ABE1`을 출발점으로 삼는다. 과거 시안의 레이아웃이 현재 MVP의 최종 디자인으로 확정된 것은 아니다.
- Impeccable용 `PRODUCT.md`, `DESIGN.md`는 아직 없다. 기존 원고·범위·브랜드 자료를 바탕으로 필요한 내용을 정리한다.

## 권장 방향

미니어처 물류 영상이 첫 화면의 인상을 만들고, 본문은 서비스·조건·비용을 빠르게 비교하고 견적을 요청하도록 구성한다. Impeccable의 방문자 모드는 견적 문의 결정을 돕는 **Persuade**로 제안한다.

2026 트렌드 자료에서 프로젝트에 적용할 만한 요소는 브랜드 고유 비주얼, 강한 타이포그래피, 먼저 훑어보고 필요한 내용을 읽는 정보 구성이다. 이는 자료를 PNPLINE에 맞춰 선택한 디자인 제안이며, 특정 스타일의 성과를 보장하는 근거는 아니다.

- Webflow: [8 web design trends to watch in 2026](https://webflow.com/blog/web-design-trends-2026). 브랜드 고유 시각 체계, 간결한 메시지, 선택적으로 탐색하는 개요 구성을 참고한다.
- Figma: [Top Web design trends for 2026](https://www.figma.com/resource-library/web-design-trends/). 입체 비주얼·모션·타이포그래피의 활용을 참고한다.

| 영역 | 적용 제안 | 판단 기준 |
| --- | --- | --- |

현재 와이어프레임의 회색 도식·격자·제작 패널은 검토 도구다. 실제 랜딩의 브랜드 표현은 별도 시안으로 만든다.

## Impeccable 제작 순서

1. **`$impeccable init`: 제품 기준 정리.** 중국 출고·미국 물류를 검토하는 방문자, 미국 직영 창고, 견적 문의라는 목표, 확정된 페이지 범위와 콘텐츠 출처를 `PRODUCT.md`로 정리한다. 이미 대화와 자료에 확정된 사실은 재사용하고 결과를 바꾸는 미결정 사항만 확인한다.
2. **`$impeccable shape`: 핵심 화면으로 방향 선택.** 같은 원고와 영상을 사용해 히어로·서비스·견적 영역의 서로 다른 구성안을 비교한다. 데스크톱과 모바일을 함께 검토하고 영상과 정보의 비중을 고른다. 글꼴·색상·간격·사진 사용·모션 원칙을 시각 기준으로 확정한다.
3. **선택한 방향으로 전체 페이지 구현.** 8개 섹션의 흐름을 실제 HTML/CSS와 인터랙션으로 완성한다. 영상 완성 전에는 기존 작업본으로 연동하고, 최종 파일의 장면 경계·길이·모바일 구도에 맞춰 매핑을 확정한다. 원고의 사실과 서비스 범위는 디자인 과정에서 임의로 바꾸지 않는다.
4. **`audit`와 `polish`: 검수 및 마감.** 접근성·반응형·시킹 성능·텍스트 대비·중국어 줄바꿈·앵커 이동을 검수하고, 발견한 문제를 묶어서 수정한다. 필요한 경우에만 `adapt`·`optimize`를 추가한다. 결과의 토큰과 사용 규칙을 `DESIGN.md`와 관련 Impeccable 기록에 남긴다.

`init`와 `shape`는 코딩 에이전트에 요청하는 스킬 작업이다. 터미널에 `npx impeccable init`를 실행하는 방식으로 사용하지 않는다. 일반적인 사용 안내는 [Impeccable 문서](https://impeccable.style/docs/)를 참고한다.

## 유지할 콘텐츠·동작 기준

- 히어로는 스크롤 위치가 영상 시점을 정하고, 역스크롤하면 이전 시점으로 이동하며 멈추면 현재 시점을 유지한다.
- 영상 끝까지 진행하지 않아도 서비스·견적에 접근할 수 있어야 한다.
- 삭제한 스크롤 안내 문구와 콘셉트 표식을 다시 넣지 않는다. S1~S7 해설표도 공개 본문에 추가하지 않는다.
- 서비스·고객·운영·상담 절차·비용·FAQ·견적 콘텐츠는 한 페이지 안에서 확인한다.
- 문의 CTA는 같은 폼으로 연결한다. 개인정보 처리방침은 별도 경로를 유지한다.
- 실제 시설·인증·WMS 증빙은 확인된 자료만 사용하고, 영상이나 생성 이미지를 증빙으로 제시하지 않는다.

## 첫 디자인 산출물

다음 작업의 목표는 제품 기준 문서와, 같은 중문 원고를 사용한 핵심 화면 구성안 비교다. 시안을 선택한 다음 전체 랜딩 구현으로 이어간다. 영상 장면의 초·프레임 배분, 최종 서비스 사실 검수, 개인정보 전문, 실제 문의 접수 연결은 각각의 확정 자료와 운영 조건을 따른다.

## Impeccable 업데이트 확인

2026-10-31 공식 npm 최신 버전과 공식 `skill-v4.8.0` 배포를 확인했다. 배포 ZIP의 Ed25519 서명, 파일 크기와 SHA-256을 검증했다. 스킬 파일은 v4.8.0으로 갱신했으며, 공식 매니페스트와 SHA-256이 일치하는 Windows 엔진 v0.1.18을 설치했다. Codex가 사용하는 사용자 스킬 런처의 `--version` 출력은 `4.8.0`이다.
